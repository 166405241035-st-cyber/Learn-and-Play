## 1. เป้าหมายและขอบเขต

ผู้เล่นเลือกพื้นที่อ่านหนังสือ ร้านเล็ก หรือพักผ่อน ขนาด4×6เมตร งบ4,000 เผื่อวัสดุ10% ซื้อเป็นกล่องเต็ม A1.5ตร.ม./180 B2ตร.ม./250 ของตกแต่งฟรี เป้าหมายไม่เปลี่ยนตัวเลขฐาน
เรียนเพื่อเลือกปริมาณซื้อและอธิบายทางเลือก ไม่ใช่จดจำคำตอบ18กล่อง หน่วยที่รองรับแรก m, cm, m², cm², กล่อง และเหรียญ ไม่เพิ่มแปลงปริมาตรหรือรูปเว้าในชุดนี้

## 4. คำใบ้สี่ระดับ — ตัวอย่างกล่องเต็ม

1. prompt: “ถ้าซื้อ17กล่อง ปริมาณที่ได้ถึง26.4ตร.ม.หรือยัง?”
2. principle: “จำนวนกล่องต้องเป็นจำนวนเต็ม และปริมาณต้องไม่น้อยกว่าที่ต้องเตรียม”
3. setup: “หาค่า26.4÷1.5 แล้วตรวจจำนวนเต็มรอบค่านั้นด้วยการคูณกลับ”
4. worked-example: “ได้17.6;17กล่อง=25.5ไม่พอ;18กล่อง=27จึงพอและเป็นจำนวนเต็มน้อยที่สุด”

เก็บเฉพาะhintที่เปิด เวลา ขั้น และattempt ช่วยได้เสมอ บทเต็มที่เปิดระหว่าง assessment เป็นassistance ไม่ลบคำตอบแรก การอ่านเงื่อนไขโจทย์ซ้ำไม่ถือเป็นคำใบ้

## 5. ทำจริงในโลกและแผนที่ต้องเก็บ

แผนมีข้อมูล/หน่วย สูตรและเหตุผล ค่าพื้นที่ ส่วนเผื่อ ต้องเตรียม กล่อง ค่าใช้จ่าย ปริมาณซื้อ สำรอง เงินเหลือ และเหตุผลเลือก เก็บแผนแรก แผนใช้จริง และฉบับแก้สำคัญ
กดใช้แผนเติมจำนวนในตะกร้าแต่ไม่ซื้อทันที แสดงยอดก่อนยืนยัน ผู้เล่นซื้อไม่พอในฝึกได้ ถ้าพลาดเสนอเปรียบเทียบวัสดุ/แก้แผน/คืนกล่องปิด/เริ่มทดลองใหม่ ไม่ให้หาเงินเพื่อซื้อสิทธิ์เรียน

| ผลที่คาดหวัง | A | B |
| --- | ---: | ---: |
| พื้นจริง / ต้องเตรียม m² | 24 / 26.4 | 24 / 26.4 |
| กล่อง / ปริมาณซื้อm² | 18 / 27 | 14 / 28 |
| ค่าใช้จ่าย / เงินเหลือ | 3,240 / 760 | 3,500 / 500 |
| เปิดขั้นต่ำเพื่อปู24 / กล่องปิด | 16 / 2 | 12 / 2 |
| วัสดุเหลือ / สำรองขั้นต่ำm² | 3 / 2.4 | 4 / 2.4 |

ทั้งสองผ่านโลกเมื่อทางใช้ถึงและมีภาพ/สรุปครบ ความสวยและเงินเหลือไม่ใช่mastery

## 8. พอร์ตและการต่อยอด

พอร์ตเก็บเป้าหมาย แปลนและภาพ เงื่อนไข task/version แผนแรก/จริง ทางเลือกและสิ่งที่แก้ ผลโลก หลักฐานรายobjective help/tools ผลตัวเลข/รอตรวจ และreflection
ข้อความตัวอย่าง: “โครงการสำเร็จ • ตัวเลขในงานข้อมูลใหม่ตรวจแล้ว • เหตุผลรอตรวจ”
คำถามreflection: “ตอนแรกเข้าใจผิดเรื่องใด?”, “ตรวจอย่างไรว่าวัสดุพอ?”, “ถ้าข้อมูลเปลี่ยนจะตรวจอะไรใหม่?” ข้อความที่แก้ไม่เปลี่ยนผลระบบ
เล่นจบเปิดการจัดแสดง/ตกแต่งตามกฎโลกที่กำหนดภายหลัง; ปลดล็อกจากความรู้ยังรอเกณฑ์ครู ไม่มีthresholdใหม่ในฉบับนี้
