หน่วยแรกคือค่าเฉลี่ยAVG01–05 ใช้[แบบผู้เรียนA/B/C/D](MEAN_LEARNER_FORMS.md), [เกณฑ์0.3](MEAN_ALIGNMENT_AND_SCORING.md), [บท0.2](../MEAN_LEARNING_UNIT.md), [แผนทดลองเดิม](MEAN_PILOT_PROTOCOL.md) คู่มือนี้เติมการดำเนินงาน/บันทึก/ตัดสินใจ ไม่แทนกติกาเรื่องชุดที่เคยเห็นและแบบที่ยังไม่สอบเทียบ

## สรุปผลโดยไม่สร้างเหตุเชิงสาเหตุ

รายงานรายทักษะและผู้เรียน: ก่อนเรียนมีหลักฐานอะไร → หลังทำเองได้อะไร → หลังเว้นระยะเหลืออะไร ภายใต้เงื่อนไขใด แยกคนที่exposed/ช่วย/ไม่กลับมาติดตาม แสดงจำนวนที่มีข้อมูลและตัวหาร เช่น“มีผลติดตามจริง n คนจากผู้ร่วมทั้งหมด N คน” ไม่เติมคะแนนผู้ขาดนัด

หากรายงานจำนวนตอบถูกให้นับเฉพาะคำตอบที่ใช้ได้และระบุแบบ/รุ่น A/Bยังไม่เทียบความยาก และC/Dต่างชนิดข้อ คะแนนเพิ่มอย่างเดียวไม่พิสูจน์ว่าเกมช่วยหรือสอบติด ไม่สรุปผลจากกลุ่มเล็กเป็นค่ามาตรฐานหลักสูตร

## ข้อผิดจริง → สิ่งที่จะปรับ → บทถัดไป

ตารางนี้เป็นกติกาเตรียมไว้ ไม่ใช่ข้อผิดที่พบจากผู้เรียนแล้ว

| หลักฐานที่พบจริง | เปลี่ยนอะไร | บทต่อที่เหมาะ | วิธีตรวจการเปลี่ยน |
| --- | --- | --- | --- |
| หารผิดเพราะนับข้อมูลผิด | เพิ่มการนับรายการก่อนสูตร ลดภาระข้อความ | F01เฉพาะจุด แล้วAVG01–02 | ข้อใหม่จำนวนรายการต่างกัน ไม่ใบ้ให้นับ |
| คิดm/nเป็นผลรวม | แสดงการแบ่งเท่ากันและเชื่อมS=nm | AVG02ก่อนหน่วยใหม่ | อธิบายผลรวมโดยไม่มีตารางเตรียม |
| จำนวนหลังเพิ่ม/ลบผิด | เพิ่มตารางก่อน–หลังพร้อมลดตัวช่วย | AVG03 หรือF04ถ้าตั้งสมการไม่ได้ | ข้อเพิ่มและลบต่างบริบท ตรวจเหตุผลทิศทาง |
| เฉลี่ยของค่าเฉลี่ยทั้งที่กลุ่มไม่เท่ากัน | คิดผลรวมกลุ่มก่อน; ถ้ารู้สูตรแต่ฐานผิดอย่าสอนคำนวณใหม่ทั้งหมด | AVG04 → RP01/04เมื่อสับสนส่วน | ข้อกลุ่มต่างขนาดและตารางความถี่ |
| คูณหารคล่องแต่ตั้งสมการไม่ได้ | สอนตัวแปรและความสัมพันธ์จากข้อความ | F04ก่อนโจทย์ย้อนกลับ/ผสม | ตั้งสมการและแทนกลับคนละบริบท |
| สรุปทุกคนจากค่าเฉลี่ย | เพิ่มตัวอย่างโต้แย้งและเปรียบชุด | AVG05 → ค่ากลางอื่นตามเส้นทาง | สร้างตัวอย่างใหม่ที่ตรงเงื่อนไข |
| หลังเรียนทำเองได้ แต่เว้นระยะต้องใบ้ | ทบทวนเรียกคืนเฉพาะทักษะ ลดการยัดบทใหม่ | ทบทวนก่อนขยายหน่วย | ข้อที่ยังไม่เคยเห็นและบันทึกเรียนระหว่างช่วง |
| ไม่เข้าใจคำถาม/ตัวอักษร/การแสดงตาราง | แก้คำสั่ง/การเข้าถึง ไม่ติดป้ายไม่รู้คณิต | ทดลองอ่านใหม่ก่อนเพิ่มบท | ถามความหมายด้วยภาษาตนเอง |
| ทุกAVGมีหลักฐานเองและคงอยู่ | เพิ่มงานเลือกวิธี/น้ำหนักทั่วไปหรือบทฐานที่วินิจฉัยขาด | RPหรือF04ตามข้อมูล; ไม่เพิ่มพร้อมกันหลายบท | ข้อผสมที่ไม่บอกชื่อสูตร |

## บันทึกการปรับหนึ่งรอบ

`change_id, evidence_ids, lesson_version_before, issue, alternative_explanation, proposed_change, affected_lesson/key/hints/rubric/items/map, reviewer_status, version_after, follow_up_item, result, decision`

เปลี่ยนหนึ่งกลุ่มปัญหาหลักต่อรอบและคงส่วนอื่นพอเปรียบเทียบได้ อย่าแก้ให้ผู้เรียนได้คะแนนจากข้อเดียวที่ฝึกซ้ำ หากเฉลย/เกณฑ์เปลี่ยนต้องตรวจหลักฐานเก่าที่ได้รับผลกระทบ แยกผลก่อน/หลังการแก้ พร้อมข้อจำกัดความเทียบเคียง

## ผลการดำเนินงานปัจจุบัน

ผู้ตรวจจริง0 / ผู้เรียนทดลองจริง0 / ผลก่อนหลัง0 / ผลติดตาม0 ไม่มีบทถัดไปที่เลือกจากข้อมูลจริงแล้ว ลำดับสำรองคือทวนAVG → วินิจฉัยRP/F04 → ผลิตเฉพาะช่องว่าง หากได้รับข้อมูลจริงจึงกรอกสรุปและปรับเอกสารตามตารางนี้ ไม่สร้างตัวเลขแทนช่องว่าง
