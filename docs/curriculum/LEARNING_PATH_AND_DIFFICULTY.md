# เส้นทางเรียน ความยาก และเงื่อนไขเปลี่ยนขั้น

9 ตุลาคม 2026 · ข้อเสนอการออกแบบ ยังไม่เป็นระบบเกมหรือกติกาที่สอบเทียบแล้ว

ใช้[ตารางทักษะ](CURRICULUM_TRACEABILITY.md)เป็นรายการสิ่งที่จะเรียน และ[คู่มือทดลอง](pilot/PILOT_RUNBOOK_AND_REVISION.md)เป็นหลักฐานปรับเส้นทาง เน้นรู้ว่าขาดอะไรและทำเองได้ ไม่ใช้เงิน/รางวัล/ความสวยหมู่บ้านตัดความรู้

## เลือกเส้นทางก่อน

| เป้าหมาย | เส้นทาง | สิ่งที่ไม่ควรถูกบังคับ |
| --- | --- | --- |
| ม.4 | วินิจฉัยF → L01–08ตามพื้นฐานและแหล่งโรงเรียนที่ยืนยันได้ | ไม่สั่งแคลคูลัสหรือใช้แนวจากผู้จัดพิมพ์เป็นข้อจริงโรงเรียน |
| Math2 | Fที่ขาด → U01–06เฉพาะBlueprintMath2 | ไม่บังคับเมทริกซ์ เวกเตอร์ เชิงซ้อน แคลคูลัส |
| Math1 | F/Lที่ขาด → U01–06ความลึกเพิ่ม → U07–10ตามprerequisite | ไม่เรียนบทตามเลขเรียงอย่างเดียว; แคลคูลัสต้องมีฟังก์ชัน/พีชคณิต |

ผู้เรียนเปลี่ยนเป้าหมายได้ ใช้หลักฐานร่วมAVG/RPต่อเมื่อขอบเขตตรงกัน หัวข้อเพิ่มเติมยังต้องตรวจแยก ปลายทางมหาวิทยาลัยต้องตรวจประกาศคณะ/รอบ/ปีจริงภายหลัง ไม่ใช้ชื่อมหาวิทยาลัยแทนชนิดข้อสอบ

## สถานะรายทักษะและการเปลี่ยน

| สถานะ | หลักฐาน | การกระทำถัดไป |
| --- | --- | --- |
| ยังไม่มีหลักฐาน | ไม่ได้รับข้อ/ข้อมูลหาย/ยังไม่เคยประเมิน | วินิจฉัยสั้น หรือเริ่มบทได้หากผู้เรียนเลือก |
| ต้องเสริม | แบบจำลอง/เงื่อนไขผิดพร้อมหลักฐาน | สอนเฉพาะจุดผิดและพื้นฐานที่จำเป็น |
| ทำได้เมื่อช่วย | ใช้ใบ้/ขั้นทำ/เห็นคำตอบ | ลดช่วยและลองข้อไม่เคยเห็น ห้ามเปลี่ยนเป็นทำเองจากคะแนนท้าย |
| ทำได้เองในงานที่ให้ | วิธีและคำตอบตรงทักษะไม่มีใบ้ ไม่มีการเห็นล่วงหน้า | เปิดบทถัดไปได้ตามพื้นฐาน แต่สถานะคงอยู่ยังรอ |
| ทำได้ซ้ำหลังเว้นระยะ | หลักฐานเองครั้งถัดไปพร้อมวัน/รุ่น/เงื่อนไข | คงสถานะเฉพาะขอบเขตที่วัด เพิ่มงานผสม/ตัวแทนใหม่ |
| มีข้อขัดกัน | บางตัวแทนทำได้ บางตัวแทนผิด หรือเหตุผลยังpending | รายงานจุดที่ยืนยัน/รอตรวจ แทนตราสีเขียวทั้งบท |

ข้อเสนอเพื่อวางบทต่อ: ใช้หลักฐานเองมากกว่าหนึ่งโอกาสและต่างตัวแทนในทักษะหลักพร้อมเหตุผลที่งานถาม ปริมาณนี้เป็นเงื่อนไขออกแบบชั่วคราว ไม่ใช่เกณฑ์จิตมิติหรือร้อยละผ่าน ใช้ผู้ตรวจพิจารณาจนมีข้อมูลสอบเทียบ

## ข้ามและกลับมาเรียน

ก่อนบทเช็กพื้นฐานที่ใช้จริง ผู้ทำงานใหม่เองได้พร้อมวิธีข้ามช่วงอธิบาย/ฝึกซ้ำได้ ผู้มีหลักฐานเฉพาะบางทักษะข้ามเฉพาะส่วนนั้น ไม่ต้องเรียนทั้งปีใหม่ บทที่ยังเป็นแผนต้องแสดง“ยังไม่มีเนื้อหา” ไม่เสนอปุ่มว่าพร้อมเรียน

ตัวอย่างค่าเฉลี่ย: AVG01–02ทำได้แต่AVG04ผิด → ข้ามสอนความหมายซ้ำ ไปผลรวมกลุ่มและน้ำหนัก; AVG03ติดตั้งสมการ → เสริมF04; RP04ย้อนฐานผิด → ดูความสัมพันธ์หลังส่วนลด ไม่ใช้การจับเวลาบังคับ

หลังเว้นระยะผิดไม่ลบประวัติที่เคยทำได้ แสดงหลักฐานใหม่และเสนอบททบทวน ใช้ตัวแทนที่ติด ไม่บังคับเริ่มต้นทั้งหมด

## ความยาก: ระดับกับเหตุที่ยากต้องแยก

| ระดับเสนอ | ลักษณะงาน | ตัวอย่างโครงการ / สิ่งที่เปลี่ยน |
| --- | --- | --- |
| D1 | แนวคิดตรง ตัวแทนคุ้น | AVG02ให้จำนวนและเฉลี่ยหาผลรวม; RP03แปลงค่าพร้อมฐาน |
| D2 | ต้องเลือกความสัมพันธ์ เชื่อมขั้น | AVG03หาเพิ่ม/ลบ; RP04ย้อนราคาก่อนลด |
| D3 | ผสมทักษะ/คุมหลายเงื่อนไข | T1ค่าเฉลี่ยรวมกับส่วนการใช้เงิน; ต้นทุนรวมค่าส่ง |
| D4 | งานไม่คุ้น/ประเมินข้ออ้าง/เหตุผลมีเงื่อนไข | ออกแบบตัวอย่างหักล้างข้อสรุปภายใต้หลายเงื่อนไขที่ไม่เคยฝึก |

ไม่ใช่ทุกโจทย์ให้เหตุผลเป็นD4โดยอัตโนมัติ ตัวอย่างโต้แย้งง่ายหลังสอนอาจD1–2 บันทึกเพิ่ม: จำนวนแนวคิด ภาระภาษา คำนวณ ตัวแทนข้อมูล ความใหม่ และprerequisite ตัวเลขยากขึ้นไม่เท่ากับแนวคิดลึกขึ้น

เก็บความยากที่ผู้ตรวจเสนอแยกจากความยากที่ผู้เรียนพบ เมื่อมีข้อมูลจริงตรวจรูปแบบผิด/ความช่วย/เวลา/อัตราตอบถูกพร้อมกลุ่มและตัวหาร ไม่มีข้อมูลให้status=uncalibrated ไม่ใช้ชื่อโรงเรียนหรือเวลาช้าเป็นระดับ

## เมื่อใดให้โจทย์ผสมและซ้อมสอบ

| ขั้น | เงื่อนไขก่อนเข้า | ลักษณะและข้อมูลที่รายงาน |
| --- | --- | --- |
| ฝึกตรงบท | บทสอน/พื้นฐานพร้อม | มีใบ้ได้ เก็บชั้นช่วย |
| ลดช่วย | ทำตามตัวอย่างได้ | เอาตาราง/สูตรสำเร็จออกทีละส่วน |
| เปลี่ยนตัวแทน | วิธีหลักมีหลักฐานเอง | ตาราง/ข้อความ/หาข้อมูลย้อน; ไม่อ้างถ่ายโอนถ้าเพียงเปลี่ยนเลข |
| ชุดผสม | ทักษะที่จะผสมมีหลักฐานเองในขอบเขตนั้น | ไม่แปะชื่อสูตร; ถ้าขาดF04ไม่ใช้ข้อสมการผสมตัดสินRP |
| ซ้อมจับเวลาเฉพาะส่วน | เข้าใจวิธีในชุดไม่จับเวลาแล้วและผู้เรียนเลือกฝึกเวลา | ระบุเป็นซ้อมส่วนย่อย ไม่ใช้90นาทีกับทุกชุด |
| ซ้อมเต็มชุด | เนื้อหา/รูปแบบตรงแหล่งสอบ ได้ตรวจข้อและไม่exposed | ใช้กติกาปีนั้น; Math2ชุด2568เต็ม100คะแนน90นาที แต่4/9เป็นคะแนนที่ทางการให้ทุกคำตอบ จึงแยกจากผลทักษะ |

ซ้อมสอบรายงานตัวเลขคะแนนกับเหตุผลที่รอตรวจแยก ไม่เอาคะแนนเกมรวมเป็นคะแนนซ้อม ถ้าใช้เฉลยสาธารณะที่ผู้เรียนเคยเห็นให้รายงานฝึกหลังเห็น ไม่ใช้เป็นผลซ้อมข้อใหม่ ต้องกันชุดประเมินก่อนเผยสอนและตรวจสิทธิ์ก่อนนำเข้าผลิตภัณฑ์
