## 1. เงื่อนไขก่อนเริ่ม

แจ้งวัดอะไร เครื่องมือที่อนุญาต ไม่มีเวลาบังคับ วิธีพัก/เก็บร่าง และการบันทึกคำใบ้ ก่อนเริ่มattempt เก็บtask/version/objectiveIds/assistanceOffered/toolsAllowed/graderKind/responseKindเป็นsnapshot

เป็นแบบเสนอสำหรับฝึกหรือassessmentตามโหมดที่ประกาศ ไม่ต้องทำทุกชุดเป็นประตูก่อนเล่น ผู้ตรวจต้องดูวิธี/เหตุผลร่วมกับค่าตัวเลข

| Task ID | เป้าหมาย / เครื่องมือ | โจทย์เขียนใหม่ | เฉลย / ขอบเขตตรวจ |
| --- | --- | --- | --- |
| SPACE-UNITS-CHECK-01 | data.units / ไม่ต้องเครื่องคิดเลข; ถ้าใช้เก็บtool | แปลนกว้าง400cmยาว6m ต้องคำนวณอะไรใหม่ก่อนหาพื้นที่? | 400cm=4m; พื้น24m²; อธิบายทำหน่วยด้านให้เหมือนกัน |
| SPACE-AREA-UNIT-CHECK-01 | data.unitsส่วนเสริม / ไม่จับเวลา | พื้น1m×1m มีพื้นที่กี่cm² และเหตุใดไม่ใช่100? | 10,000cm²; สองด้าน100cm; คำอธิบายpendingถ้าไม่มีผู้ตรวจ |

| แผนD | boxes,purchasedCoverage,cost,reserve,remainingBudget | 11,16.5,1980,1.5,120 | รับรู้กรณีพอดีและเปรียบเทียบ |

เลขทศนิยมเก็บหน่วยที่แน่นอนภายใน เช่นcm²:150000/15000/165000 ไม่ปัดเลขให้คำตอบผิดดูผ่าน ช่องว่างคือnot-provided ไม่ใช่0 รับlocaleตัวเลขก่อนตรวจอย่างชัดเจน; NaN/Infinity/ค่าติดลบในช่องปริมาณปฏิเสธ

## 4. ผลและระดับหลักฐาน

| สภาพคำตอบ | ข้อความที่แสดงได้ | สิ่งที่ห้ามสรุป |
| --- | --- | --- |
| กรอกไม่ครบ | “ยังไม่มีข้อมูลส่วน… บันทึกร่างหรือเติมก่อนส่งได้” | ไม่มีคะแนน0อัตโนมัติแทนข้อมูลที่ขาด |
| ค่าไม่ถูก | “จำนวนที่เลือกทำให้วัสดุได้… แต่ต้องเตรียม…” ตามโหมดfeedback | ห้ามเปิดเฉลยเต็มในงานอิสระโดยไม่บันทึกช่วย |
| ตัวเลขถูก เหตุผลยังไม่ตรวจ | “ช่องตัวเลขผ่านตรวจ • วิธีและเหตุผลรอตรวจ” | ไม่มีbadgeเชี่ยวชาญหรือindependent mastery |
| เปิดตัวอย่างแล้วตอบถูก | “ตอบได้โดยใช้ตัวอย่าง” พร้อมhelpที่ใช้ | ไม่ลบhelpแล้วเรียกทำเอง |
| ผู้ตรวจตรวจแล้ว | แสดงverdictรายด้าน evidence source reviewer/date/version | reviewedไม่ได้แปลว่าผ่านทุกด้าน |

verdictตัวเลขอยู่ระดับfield-check ไม่ยืนยันทั้งdimension calculate-checkหากคำอธิบายวิธีตรวจยังpending ควรแยกnumericCheckStatusกับreasoningReviewStatusในการออกแบบruntime
ความช่วยและผลถูกผิดเป็นคนละแกน ไม่ตั้งคะแนนรวมผ่าน80%หรือจำนวนattemptยืนยันใหม่ ผลโลกไม่เพิ่มmastery pendingไม่ให้knowledge unlock

## 5. ตัวอย่างC/Dสำหรับทบทวนrubric

- คำตอบ1: “C14 ราคา1960” — สองช่องตัวเลขตรวจได้ แต่ข้อมูลเผื่อ การตรวจ และเหตุผลยังขาด ไม่ยืนยันด้านทั้งหมด
- คำตอบ2: “15×1.1=16.5; C14ได้16.8 เหลือ1.8≥1.5 ราคา1960≤2100; D11ได้16.5 เหลือ1.5 ราคา1980≤2100; เลือกDเพราะชอบรูปแบบและยอมรับว่าเหลืองบน้อยกว่าC20” — ทั้งสองตัวเลือกถูก เหตุผลรอผู้ตรวจแต่ห้ามหักเพราะเลือกD
- คำตอบ3: ค่าเหมือนข้อ2แต่เปิดworked-example — ค่าถูกพร้อมเงื่อนไขassisted ไม่ใช่หลักฐานทำเอง
- คำตอบ4: C13ราคา1820และอ้างใกล้จำนวนที่หารได้ — ซื้อได้ในฝึกแต่ปริมาณ15.6<16.5; feedbackให้ตรวจปริมาณกับเป้าหมาย ไม่ใช้ความสวยตัดสิน
- คำตอบ5: เลือกCเพราะ“ทนกว่า” — เลขอาจถูกแต่เหตุผลอ้างข้อมูลที่ไม่ให้ ผู้ตรวจขอแก้การอ้างเหตุผล ไม่เติมความทนทานให้โจทย์ย้อนหลัง

ทั้งหมดเป็นตัวอย่างออกแบบ ไม่มีผลผู้ตรวจจริง เก็บการแก้คำตอบ/ผลเป็นฉบับใหม่เพื่อให้พอร์ตแสดงพัฒนาการ ไม่ทับผลเดิม

## 6. รายการตรวจคุณภาพก่อนทดสอบผู้เล่น

ทุกobjectiveมีlesson+practice+งานที่เก็บหลักฐานตรงสิ่งที่วัดหรือระบุยังไม่มี ไม่อ้างทักษะจากงานที่ไม่ได้วัด; หน่วย/actual/reserveแยก; ค่าทุกแผนสอดคล้อง; ยอมรับC/D; ช่วยบันทึกจริง; พักแล้วร่างไม่หายเมื่อsaveimplemented; ข้อมูลพอร์ตเชื่อมattempt/version; แก้captionไม่แก้ผล; mockวิชาอื่นไม่ใช้ตัวตรวจตัวเลขนี้
ครูต้องตรวจขอบเขต partial ความชัดคำถาม ตัวอย่างระดับ หลักฐานการคำนวณเอง วิธีreviewและความสอดคล้องผู้ตรวจ ก่อนนิยามconfirmed mastery งานนี้ยังไม่ผ่านขั้นนั้น
