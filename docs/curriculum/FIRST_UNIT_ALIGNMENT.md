## 3. สิ่งที่แก้ในการออกแบบชุดแรก

1. L01ต้องอธิบายทั้งความยาวกับพื้นที่: 1m=100cmแต่1m²=100×100cm² แยกการประเมินสองส่วน; หน่วยภายในcm²ไม่บังคับให้ผู้เล่นแปลงทุกครั้ง
2. L02เพิ่มวิธีขยายตัวตั้ง/ตัวหารด้วยตัวเดียวกัน: 7.2÷1.2=72÷12=6 ตรวจ6×1.2=7.2 แล้วโยง26.4÷1.5=264÷15=17.6 ไม่ใช่ย้ายจุดเฉพาะตัวหาร
3. L03ให้แยกพื้นที่กับเส้นรอบรูปด้วยคำถามเลือกสิ่งที่ต้องหา แต่ไม่อ้างประเมินเส้นรอบรูปครบ
4. L04แสดงเศษส่วน10/100=0.1กับการคูณฐานพื้นที่ ก่อนใช้ทางลัด×1.1; แยกactualArea/allowance/requiredCoverage
5. L05ต้องมีกรณีหารลงตัว เช่น12÷3=4 เพื่อไม่สอนว่าต้องบวก1ทุกครั้ง เลือกจำนวนเต็มที่น้อยที่สุดและยังพอ
6. L06–L08ต้องตรวจทั้งสองแผนก่อนเลือก ไม่ให้เลือกวัสดุถูกที่สุดแทนเหตุผล ตรวจงบ/สำรอง/ข้อมูลที่ไม่มี

## 4. ตรวจความครอบคลุมของงานประเมิน

งานC/Dเพียงชุดเดียวไม่มีหลักฐานการแปลงหน่วย และผู้ใช้เครื่องคิดเลขไม่ได้แสดงการคำนวณทศนิยมเอง เพิ่มcheckpointเฉพาะก่อนอ้างทักษะดังกล่าว ดู FIRST_UNIT_ASSESSMENT
คำตอบตัวเลขถูกยืนยันเฉพาะช่องนั้น สูตร/วิธี/ตรวจ/เหตุผลที่เป็นข้อความเป็นpending ไม่มีครูตรวจออนไลน์ในต้นแบบ ห้ามอ้างassessed masteryจากการซื้อสำเร็จ
งานbaseline/postยังไม่เทียบความยากและผลC/Dบริบทเดิมไม่ใช่broad transfer งานผ้าคลุมเป็นdraftต้องตรวจความสมจริงก่อนเปิดใช้

## 5. สิ่งที่พร้อมและที่รอ

พร้อมเป็นเอกสาร: source anchors, ความสัมพันธ์partial/process, ขอบเขตบทสอนที่ต้องเพิ่ม และแบบงานตรวจรายทักษะ
ยังรอ: ครูทบทวนศัพท์ ความเหมาะสมและตัวอย่างหลักฐาน; หลักสูตรส่วนอื่น; เกณฑ์mastery/retention; ตัวตรวจจริง; pilotผู้เรียน ไม่ต้องรอสิ่งเหล่านี้เพื่ออ่านบทเรียนหรือออกแบบUI แต่ห้ามรายงานว่ารับรองแล้ว
