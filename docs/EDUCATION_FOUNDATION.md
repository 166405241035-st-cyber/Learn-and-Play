# ฐานการเรียนรู้และการเตรียมสอบ — Learn-and-Play

9 ตุลาคม 2026 · แบบเสนอเพื่อพัฒนาต่อ ไม่ใช่หลักสูตรหรือคลังข้อสอบที่ผลิตเสร็จ

## 1. ข้อตกลงล่าสุด

ให้ความสำคัญกับความรู้ ความเข้าใจ และการเตรียมสอบก่อน ระบบหมู่บ้านและเควสออกแบบภายหลังให้รองรับเนื้อหา ผู้เล่นจัดสรรพื้นที่โดยตรง ไม่มีตัวละครผู้เล่นเดิน ไม่สร้างระบบเดิน/กล้องตามตัวละคร เป้าหมายมีสองเส้นทาง: สอบเข้า ม.4 และเตรียมเข้ามหาวิทยาลัย ไม่รวมทั้งสองระดับเป็นบันไดเดียวจนผู้เรียนต้องผ่านเนื้อหาที่ไม่เกี่ยวกับเป้าหมาย

การเตรียมสอบต้องแสดงว่าผู้เรียนทำโจทย์ใหม่ได้เองและอธิบายได้ ไม่ใช้ยอดเงิน ความรุ่งเรือง เวลาที่เล่น หรือจำนวนบทที่เปิดเป็นหลักฐานว่าเก่งขึ้น ไม่รับรองผลสอบเข้าจากการเล่นเพียงอย่างเดียว

## 3. วิธีรับข้อสอบเข้าคลัง

1. เก็บต้นทาง ผู้เผยแพร่ สนาม ปี รอบ วิชา หน้า/เลขข้อ วันที่ตรวจ และสถานะการใช้เนื้อหา
2. ระบุชนิด: ข้อสอบจริงทางการ / ตัวอย่างทางการ / เรียบเรียงจากความจำ / แนวข้อสอบสำนักพิมพ์ / โจทย์ที่โครงการแต่ง ห้ามผสมป้าย
3. อ่านต้นฉบับตรวจสัญลักษณ์ รูป หน่วย และเงื่อนไข ไม่ใช้ OCR โดยไม่มีคนเทียบ
4. ผู้ตรวจคณิตศาสตร์แก้โจทย์เอง ตรวจคำตอบและเหตุผล เทียบเฉลย ระบุวิธีอื่นที่ถูก หากขัดกันให้พักข้อไว้
5. จัดทักษะหลัก ทักษะรอง ความรู้ก่อนเรียน จุดผิดที่คาดว่าจะพบ และรหัสหลักสูตรที่ตรวจเอกสารแล้วเท่านั้น
6. ตรวจซ้ำและจัดตระกูลข้อ: ข้อเปลี่ยนเลขหรือเปลี่ยนฉากจากต้นเดียวกันอยู่กลุ่มเดียว เพื่อป้องกันฝึกแล้วจำไปตอบข้อประเมิน
7. ตรวจสิทธิ์ก่อนคัดลอกลงผลิตภัณฑ์ การเปิดอ่านได้ไม่เท่ากับอนุญาตให้เผยแพร่ซ้ำ ระหว่างยังไม่ชัดให้เก็บลิงก์และข้อมูลอ้างอิง ไม่อัปโหลดข้อสอบทั้งเล่ม

## 4. โครงทักษะก่อนเขียนบทเรียน

ตารางเป็นโครงเสนอ ไม่ใช่สรุปความถี่ออกสอบหรือผังตัวชี้วัดที่ตรวจครบ

| เส้นทาง | กลุ่มความรู้ | ตัวอย่างความรู้ก่อนเรียน / สิ่งที่ต้องพิสูจน์ |
| --- | --- | --- |
| ฐานร่วม | จำนวน เศษส่วน ทศนิยม อัตราส่วน ร้อยละ หน่วย | คำนวณและประมาณค่าได้ อธิบายปริมาณที่อ้างอิง |
| ม.4 | พีชคณิต สมการ อสมการ ระบบสมการ พหุนามและกำลังสอง | แปลงข้อความเป็นความสัมพันธ์ ตรวจคำตอบกับเงื่อนไข |
| ม.4 | เรขาคณิต การวัด พีทาโกรัส ความคล้าย และตรีโกณมิติพื้นฐาน | อ่านรูป เลือกสมบัติ แยกพื้นที่กับความยาว ตรวจหน่วย |
| ม.4 | สถิติ ความน่าจะเป็น และการให้เหตุผล | อ่านข้อมูล แยกกรณี อธิบายเหตุผลไม่ใช่จำสูตร |
| มหาวิทยาลัย | จำนวนและพีชคณิตตาม Blueprint Math1/Math2 | แยกเนื้อหาที่ใช้จริงในแต่ละวิชาและพื้นฐานที่ขาด |
| มหาวิทยาลัย | เรขาคณิต สถิติ ความน่าจะเป็น และแคลคูลัสตามขอบเขตวิชาที่เลือก | ไม่บังคับแคลคูลัสกับผู้เรียนทุกเส้นทาง จับคู่ขอบเขตทางการก่อนผลิต |

เขียนผัง prerequisite รายทักษะ เช่น เศษส่วน → อัตราส่วน → ร้อยละ → ปัญหาหลายเงื่อนไข; การจัดรูปนิพจน์ → สมการ → ระบบสมการ → การสร้างแบบจำลอง ควบคู่ทักษะอ่านโจทย์ รูป กราฟ และตรวจคำตอบ ไม่ทำให้ทุกคนเรียนทั้งบทใหม่เมื่อผิดเพียงทักษะย่อย

ความสำคัญของบทพิจารณา 3 อย่าง: เป็นพื้นฐานให้เรื่องอื่นหรือไม่ มีหลักฐานจากข้อสอบกี่ชุด และผู้เรียนกลุ่มเป้าหมายติดตรงไหน บันทึกจำนวนชุดที่วิเคราะห์และตัวหารก่อนแสดงเปอร์เซ็นต์ความถี่ ห้ามทำนายปีหน้าจากข้อสอบปีเดียว

## 5. ความยากและลำดับฝึก

ใช้ระดับชั่วคราว D1 แนวคิดตรง / D2 เลือกวิธีและเชื่อมขั้น / D3 หลายเงื่อนไขหรือหลายทักษะ / D4 ให้เหตุผลหรือแก้ปัญหาที่ไม่คุ้น พร้อมบันทึกภาระอ่าน จำนวนแนวคิด ความซับซ้อนคำนวณ รูปแบบตัวแทน และความใหม่ ไม่ตัดสินจากชื่อโรงเรียน ความยาวโจทย์ หรือจำนวนขั้นอย่างเดียว

ระดับนี้เป็นความเห็นผู้ตรวจจนมีข้อมูลทดลอง เก็บอัตราตอบถูก รูปแบบผิด เวลา และการขอช่วยแยกตามกลุ่มที่พื้นฐานต่างกัน แล้วปรับระดับ ไม่ใช้เวลาช้าอย่างเดียวตัดว่าไม่เข้าใจ

ลำดับต่อทักษะ: วินิจฉัยพื้นฐานสั้น → อธิบายแนวคิด → ตัวอย่างคิดออกเสียง → ฝึกมีคำใบ้ → ลดความช่วย → โจทย์เปลี่ยนรูปแบบ → ชุดผสม → ประเมินข้อใหม่ → ทบทวนภายหลัง ผู้ผ่านพื้นฐานข้ามบทได้และกลับมาเรียนเมื่อจำเป็น

## 6. แม่แบบบทเรียนที่ต้องผลิต

หนึ่งบทต้องมี: เป้าหมายที่ตรวจได้, prerequisite, คำถามเช็กก่อนเรียน, คำอธิบายหลักการ, ภาพ/ตารางที่ถูกต้อง, ตัวอย่างพร้อมเหตุผลทุกช่วง, วิธีอื่นเมื่อมีประโยชน์, ข้อผิดพลาดและตัวอย่างโต้แย้ง, ฝึกแบบลดความช่วย, ข้อเปลี่ยนบริบท, คำอธิบายเฉลย และงานประเมินแยกชุด

ข้อเสนอเวลาเป็นช่วงสำหรับทดลอง ไม่ใช่กติกาจับเวลา: สอน 5–10 นาที ฝึก 10–15 นาที และตรวจความเข้าใจ 5–10 นาที แบ่งพักได้ บันทึกร่างได้ ปรับหลังทดลองจริง โหมดเรียนไม่บังคับเวลา โหมดซ้อมสอบจึงใช้เวลาตามชุดสอบที่ตรวจต้นทางแล้ว

คำใบ้สามชั้น: ชี้สิ่งที่ต้องหา → ชี้ความสัมพันธ์/ภาพช่วย → สาธิตขั้นต้น พร้อมบันทึกชั้นที่ใช้ การตอบหลังเปิดเฉลยไม่ถือเป็นหลักฐานทำได้เอง

## 7. ตัวอย่างหนึ่งหน่วยที่ลงรายละเอียดต่อได้

**อัตราส่วนและร้อยละ** — ตัวอย่างต่อไปนี้โครงการแต่ง ไม่ใช่ข้อสอบโรงเรียนใด

เป้าหมาย: เลือกฐานร้อยละถูก คำนวณการเปลี่ยนแปลงต่อเนื่อง และอธิบายว่าทำไมบวกร้อยละตรง ๆ ไม่ได้ พื้นฐาน: เศษส่วน การคูณ และการอ่านปริมาณ

ตัวอย่างสอน: ราคา 800 บาทลด 20% แล้วเพิ่ม 10% จากราคาหลังลด ได้ 800×0.8×1.1 = 704 บาท ซึ่งต่ำกว่าราคาเดิม 12% ต้องระบุว่า 10% อ้างอิง 640 บาท ไม่ใช่ 800 บาท ตรวจด้วยประมาณค่าและเปรียบเทียบราคาเดิม

ฝึก: แยกโจทย์หาเปอร์เซ็นต์/หาปริมาณ/หาฐานเดิมก่อนผสมเงื่อนไข วิเคราะห์คำตอบผิด “ลดสุทธิ 10%” แล้วให้ผู้เรียนอธิบายฐานที่เปลี่ยน งานประเมินควรมีรูปแบบต่างจากตัวอย่าง เช่นอ่านตาราง หรือหาค่าเริ่มต้น ไม่ใช้เพียงเปลี่ยนเลขในสูตรเดิม

ก่อนนำบทนี้เป็นบทแรกจริง ต้องจับคู่ข้อสอบที่ตรวจแล้วและทดลองกับผู้เรียน ยังไม่ประกาศว่าหน่วยนี้ครอบคลุมข้อสอบเป้าหมายทั้งหมด

## 8. หลักฐานว่าเรียนรู้และช่วยเตรียมสอบ

แยกคลังสอน/ฝึกออกจากคลังวินิจฉัยและประเมินตั้งแต่ระดับตระกูลข้อ กันชุดสอบบางชุดไว้ประเมินก่อนนำมาอธิบาย หากเปิดเฉลยแล้วต้องเปลี่ยนชุด ไม่เรียกผลหลังเห็นคำตอบว่าเป็นผลทดสอบใหม่

รายงานต่อทักษะ: คำตอบถูก ความถูกต้องของเหตุผล การเลือกวิธี การตรวจเงื่อนไข ความช่วย และการทำข้อใหม่ หลักฐานมี 4 สถานะเสนอ: ยังไม่มีหลักฐาน / ทำได้เมื่อช่วย / ทำได้เองในชุดใหม่ / ทำได้เองซ้ำหลังเว้นระยะ ตัวเลขตรวจอัตโนมัติได้แยกจากเหตุผลที่รอผู้ตรวจ ไม่กำหนดเปอร์เซ็นต์ผ่านถาวรก่อนตรวจคุณภาพข้อและทดลอง

ทบทวนเสนอครั้งแรกหลัง 2–3 วัน และอีกครั้งหลัง 1–2 สัปดาห์ ปรับตามผลจริงและตารางผู้เรียน ไม่ใช้การกลับมาเล่นทุกวันเป็นเงื่อนไขว่ารู้ มีชุดผสมเพื่อทดสอบว่าผู้เรียนเลือกวิธีเองได้เมื่อไม่มีชื่อบทบอกใบ้

ทดลองหน่วยแรกกับผู้เรียนเป้าหมาย: ก่อนเรียน → หลังเรียนด้วยชุดเทียบเคียงที่ไม่ซ้ำ → หลังเว้นระยะ ตรวจความเข้าใจและความผิดที่ลดลงร่วมกับเวลาและความช่วย ไม่อ้างผลคะแนนเพิ่มเป็นเหตุจากเกมโดยตรงหากไม่มีการออกแบบเปรียบเทียบที่เหมาะสม

พอร์ตภายหลังเก็บคำตอบ/เหตุผลฉบับแรกและแก้ไข รุ่นโจทย์ แหล่งอ้างอิง บทที่เรียน ความช่วย และผลข้อใหม่ ไม่เก็บเพียงภาพหมู่บ้านหรือเหรียญ

## 9. แผนงานและเงื่อนไขส่งต่อ

| ลำดับ | งาน | ผลงาน / เงื่อนไขตรวจ |
| --- | --- | --- |
| 1 | ตรวจต้นทางเพิ่ม | ทะเบียนแหล่งและสถานะรายชุด แยกโรงเรียน/มหาวิทยาลัย/จริง/ตัวอย่าง/แนวครบ |
| 2 | วิเคราะห์ชุดตั้งต้น | เริ่ม Math1 ปี 2568 ที่เปิดได้ เก็บทุกข้อพร้อมวิธีแก้และทักษะ; หา Math2 และชุด ม.4 ที่ยืนยันได้ต่อ ไม่อ้างว่าเสร็จในรอบนี้ |
| 3 | จับคู่หลักสูตร | ตารางรายทักษะ→ตัวชี้วัด/ขอบเขต→prerequisite→ข้ออ้างอิง มีผู้ตรวจ |
| 4 | ออกแบบวินิจฉัยและแผนเรียน | ผู้เรียนเลือกเส้นทางได้ ตรวจพื้นฐานแล้วเสนอสิ่งที่ต้องเสริม ไม่ใช้ชื่อโรงเรียนตัดระดับ |
| 5 | ผลิตหนึ่งหน่วยครบ | บทสอน ฝึก เฉลย คำใบ้ ข้อผิด และข้อประเมินต่างตระกูล ตรวจคณิตศาสตร์ครบ |
| 6 | ทดลองและปรับ | มีหลักฐานทำข้อใหม่ เหตุผล และทบทวน ตรวจจุดงงและภาระเวลา |
| 7 | ค่อยเชื่อมเกม | งาน NPC ระบุทักษะและการตัดสินใจจริง ไม่ฝืนทุกเนื้อหาเป็นค่าเช่า; เรื่องที่ไม่เข้าบริบทเรียนและฝึกตรงได้ |
| 8 | ระบบ/UI/โค้ด | ออกแบบให้ข้อมูลการเรียนไม่สูญหาย ก่อนเริ่มโค้ดต้องได้รับคำสั่งเริ่มใหม่ |

งานที่ทำแล้วรอบนี้: ตรวจแหล่งเว็บระดับรายการและกำหนดฐานออกแบบ งานที่ยังไม่ทำ: คลังรายข้อ ตัวชี้วัดรายทักษะ เฉลยที่ตรวจครบ บทเรียนผลิตจริง การทดลองผู้เรียน ระบบเกมและโค้ดใหม่
