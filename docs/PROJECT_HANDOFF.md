# Learn-and-Play — ส่งต่องานหลังเริ่มออกแบบใหม่

9 ตุลาคม 2026 · ฐานปัจจุบันคือ [GAME_CONCEPT](GAME_CONCEPT.md)

## สถานะที่ใช้ส่งต่อปัจจุบัน — ชุด6ขั้น

ผู้ใช้สั่งทำงานฐานความรู้ทั้ง6ขั้นในรอบเดียว ดู [SIX_STEP_DELIVERY](curriculum/SIX_STEP_DELIVERY.md) เป็นสถานะหลัก: ตาราง69แถวครอบคลุมกลุ่มที่วางไว้ (ยังมีช่องบท/ข้อจริงรอ), Math2ปี2568ทะเบียน30ข้อแก้12ข้อ/P16/X2, เพิ่มpreviewแนวม.4สองแหล่ง, ตรวจและแก้บทAVG/RPกับเกณฑ์, คู่มือทดลอง/ใช้ผลปรับบท, เส้นทางและความยาก

บทAVG/RPรุ่น0.2 เกณฑ์ค่าเฉลี่ย0.3 แยกpending_evidenceจาก0ผิด; แบบA/B/C/Dยังไม่สอบเทียบ น้ำหนักหน่วยกิตสอนเพิ่มแต่ไม่อยู่แบบติดตามเดิม Math2ข้อ4/9ทางการให้ทุกคำตอบ ห้ามใช้เป็นหลักฐานความรู้ ข้อจริงม.4ยังไม่ยืนยัน ไม่ยกระดับpreviewเป็นข้อจริง

ไม่มีครูตรวจจริง/ความเห็นภายนอก ไม่มีผู้เรียนทดลองหรือผลคงอยู่ ไม่เลือกบทจากผลที่ยังไม่มี ขั้นที่ต้องมีคนจริงเตรียมเครื่องมือแล้วเท่านั้น งานต่อคือผู้ใช้จัดผู้ตรวจ/ผู้เรียน → ปิดข้อผิดสำคัญ → ทดลองAVG → ใช้หลักฐานปรับตามคู่มือ ไม่เริ่มโค้ดใหม่ ไม่ติดต่อใครแทนผู้ใช้

ส่วนบันทึกข้างล่างเป็นประวัติแต่ละรอบ ตัวเลข5/30,21/30,ร่าง0.1/0.2ของเกณฑ์ในบันทึกเก่าไม่ใช่สถานะปัจจุบัน ให้ใช้ดัชนีและรายงานชุดล่าสุด

## คำสั่งล่าสุดและสถานะจริง

ผู้ใช้ให้กลับมาคุยการออกแบบก่อน หลังต้นแบบ GUI/การเล่นเข้าใจยาก ตัดหมุนกล้อง และเสนอหมู่บ้านที่รับคน/ช่วยจัดสรรแปลงและพัฒนากิจการ ร้านเข้าผ่านแผนที่และเปลี่ยนฉากเป็นNPCกับฉากหลังร้าน ผู้ใช้ยอมรับสรุปแล้วสั่งล้างโค้ดและdocเก่า

ปัจจุบันลบต้นแบบเก่า (`src`, `tests`, scaffold/build config, index และ dependency manifests) รวมถึงเอกสาร/พร็อมป์ฐานเดิมออกจากmainแล้ว มีเอกสารคอนเซ็ปใหม่ คำแนะนำส่งต่องานและสถานะภาพ ไม่มีเกมฉบับใหม่ที่รันได้ ยังไม่เริ่มโค้ดใหม่

ภาพคอมมิช33PNGใน `asset-prompts/Illustrative image/` เก็บต้นฉบับครบและยังไม่approvedตามแบบใหม่ การล้างนี้เป็นcommitปกติ ไม่เขียนประวัติGitใหม่ งานก่อนล้างดูได้ที่ [commit275649a](https://github.com/166405241035-st-cyber/Learn-and-Play/tree/275649afb0d4e96fa802846e3dd88a5ac2b39631) แต่ไม่ถือเป็นrequirementปัจจุบัน

## เป้าหมายที่ต้องรักษา

Sandboxคณิตศาสตร์มัธยม ผู้เล่นดูแลหมู่บ้าน เลือกรับคำขอ ช่วยแก้ปัญหา ออกแบบและแก้แผน การสอนตรง ๆ การประเมินจากหลักฐานแยกจากความสำเร็จโลกและพอร์ต เตรียมรองรับวิชาอื่นภายหลัง ภาพผลิตภายนอก

## งานถัดไป

คำสั่งล่าสุด: ไม่มีตัวละครผู้เล่นเดิน เน้นฐานความรู้ก่อนเกมและเควส ใช้ [EDUCATION_FOUNDATION](EDUCATION_FOUNDATION.md) ตรวจแหล่งข้อสอบ จัดทักษะ/พื้นฐาน บทสอนและหลักฐานเรียนรู้ก่อนออกแบบที่ดิน/เงินและ GUI ผู้ใช้ยังไม่ยืนยันค่าเช่า ขนาดแปลง งบ รายได้ รอบเวลา หรือเกณฑ์ความรุ่งเรือง บ้าน/ของชำเป็นข้อเสนอเริ่มต้น ร้านอาหารภายหลัง

อ่าน AGENTS.md, GAME_CONCEPT, SETUP_WINDOWS และ ART_STATUS; ตรวจไฟล์จริงก่อนทำงาน ไม่ใช้ความจำโค้ดเก่าหรือผลทดสอบเก่าอ้างว่าเกมใหม่มีแล้ว อัปเดตเอกสารนี้หลังผู้ใช้แก้แนวคิด
