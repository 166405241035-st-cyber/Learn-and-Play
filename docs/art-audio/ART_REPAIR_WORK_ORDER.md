# เอกสารส่งทำภาพ: แก้ชุดเดิมและเพิ่มชิ้นที่ขาด

9 ตุลาคม 2026 · ใช้ส่งให้ผู้วาดหรือบริการสร้างภาพภายนอก

[เปิดใบงานพร้อมพร็อมป์ทุกกลุ่ม](../../asset-prompts/prototype/ART_REPAIR_AND_MISSING_PROMPTS.md)

ใบงานระบุ reference จากไฟล์จริง 33 ชิ้น ไฟล์ปลายทาง canvas จุดยึด มุม เฟรม และพร็อมป์สำหรับพื้น ตัวละคร อาคาร/หลังคา เฟอร์นิเจอร์ ต้นไม้ ธง และของคงที่ ไม่เปลี่ยนต้นฉบับ และยังไม่สร้างภาพใหม่ในรอบนี้

ลำดับแนะนำ: ชุดสไตล์เล็ก → พื้น2:1 → คู่เดิน/ต้นไม้/ธง → อาคารAคู่ชั้นและมุม0/1 → เฟอร์นิเจอร์ทิศ → ชุดที่เหลือ ไม่ต้องส่งผลิตครบ83/119ไฟล์ทันที

ดู [ผลตรวจภาพ](COMMISSIONED_ART_REVIEW.md) เพื่อทราบเหตุผลแก้แต่ละกลุ่ม และ [สเปกผลิต](PROTOTYPE_PRODUCTION.md) เพื่อดูฐาน/หน่วยจริง ภาพที่กำลังแก้ใช้ placeholder ใน runtime ต่อ; การส่งพร็อมป์ไม่เท่ากับภาพได้รับอนุมัติหรือรวมเกมแล้ว
