## บทสอนตรง ๆ งานฐาน
1. ต้องหา:ปริมาณวัสดุที่ซื้อได้จริงและไม่เกินงบ ไม่ใช่แค่พื้นที่ห้อง
2. ข้อมูล:กว้าง4ยาว6เมตร ความจุและราคาแต่ละกล่อง เผื่อ10% ของพื้นที่
3. หลักการ:พื้นที่=กว้าง×ยาว; ต้องเตรียม=พื้นที่×1.1; จำนวนกล่อง=ปัดขึ้น(ต้องเตรียม÷ความจุ)
4. คำนวณ/ตรวจ:24;26.4; A17.6จึง18;27พอ;3240ไม่เกิน4000
5. ตีความ:Aสำรอง3เหลือ760; Bสำรอง4เหลือ500 ทั้งคู่ใช้ได้ เลือกพร้อมเหตุผลจากข้อมูลที่มี

คำใบ้ชวนคิด:“กำลังหาความยาวหรือพื้นที่?” หลักการ:“พื้นที่สี่เหลี่ยมใช้กว้าง×ยาว” ตั้งคำนวณ:“ลองเขียน24×(1+10/100)” วิธีเต็ม:“24×1.1=26.4;26.4÷1.5=17.6 จึงซื้อ18กล่อง” บันทึกเฉพาะที่เปิดจริง

## ข้อความผิด/กู้คืน
- จำนวนซื้อ:“จำนวนกล่องต้องเป็นจำนวนเต็มตั้งแต่1ขึ้นไป”
- เงินไม่พอ:“ต้องใช้… แต่โครงการเหลือ… ลองลดจำนวนหรือแก้แผน”
- คืนไม่ได้:“คืนได้เฉพาะกล่องยังไม่เปิด ล็อตนี้เหลือ…กล่อง”
- สำรองไม่พอ:“ปูครบแล้ว แต่สำรองชนิดที่ปูยังขาด…ตร.ม.”
- การช่วยประเมิน:“เปิดคำใบ้ได้ งานครั้งนี้จะระบุความช่วยเหลือที่ใช้” เปิดต่อได้
- ส่งแล้ว:“ตัวเลขตรวจแล้ว เหตุผลยังรอตรวจ จึงยังไม่มีการยืนยันทักษะครบ”
- รีเซ็ต:“เริ่มการทดลองใหม่ด้วยงบ4000 งานและหลักฐานเดิมยังเก็บอยู่ วัสดุเดิมไม่ย้ายมา” ให้ยืนยันก่อน
- เซฟล้มเหลว:“บันทึกครั้งนี้ไม่สำเร็จ อย่าเพิ่งปิดหน้านี้ ลองใหม่หรือส่งออกข้อมูลกู้คืน”

ซื้อยืนยันแสดงสินค้า/จำนวน/ยอด/เงินหลังซื้อ เปิดกล่องแสดงจำนวนที่จะเปิดก่อนปู การย้อนจัดของไม่ย้อนซื้อ
ร่างยังอยู่เมื่อปิด/กลับ; overlay ไม่ปล่อยคลิกทะลุ; ปุ่มช่วยอ่านได้เสมอ; ใช้ข้อความ/สัญลักษณ์คู่สี; ขยายข้อความไทยและหน่วย; ลด motion ไม่กระทบผลประเมิน
