# ผลพัฒนาตามแผน 7 จุด + E1/E2/E5 และเตรียม E6

9 ตุลาคม 2026 · ผู้ใช้สั่งเริ่มแก้ตามแผนและเลือก E1 + E2 + E5; เตรียม E6 สำหรับพอร์ต

รอบนี้เป็นการพัฒนาต้นแบบจริงตามคำสั่งใหม่ ไม่ใช่รอบเอกสารอย่างเดียว ใช้ฐานกล้อง/HUD/ร้านจากรอบก่อน เติมการจัดของ เปรียบเทียบแผน สมุดช่วย และหลักฐานฉบับแผน ภาพโลกยังเป็น placeholder; ไม่โหลดภาพที่มีมุม/เฟรม/registration ผิดให้ดูเหมือนชุดพร้อมแล้ว

## 2. กติกาที่ใช้ในการจัดของ

ตรง SCENE_OBJECT_SPEC: โต๊ะ1 เก้าอี้2 ชั้น1 ม้านั่ง1 กระถาง2 ทั้งหมดฟรีต่อ attempt ใช้พื้นที่ x4–7,y15–20 เว้น entry(7,15) ฐานห้ามซ้อนกันและตัวละคร ด้านหน้าอย่างน้อยหนึ่งช่องของชิ้นที่ต้องใช้งานต้องเดินถึงจากentry โดยเดินภายในพื้น

หมุนเปลี่ยนฐาน2×1↔1×2และ front cells ตามทิศจริง ไม่เปลี่ยนพิกัดคณิตตามภาพกล้อง การย้าย/undo/redo ที่ไม่ผ่านไม่ทำลายผังเดิม ย้อนการจัดไม่ย้อนเงิน ซื้อ/คืนหรือวัสดุ เปิดทดลองใหม่ได้ของ7ชิ้นชุดใหม่โดยประวัติเดิมอยู่ใน session ของเดิมไม่โอนมาเพิ่มจำนวน

ของที่วางแล้วเป็น dynamic blockers ของการเดิน การเปลี่ยนผัง/เข้าโหมดวางยกเลิกคำสั่งเดินเก่าและ callback เพื่อไม่ให้เปิดหน้าร้านจากเส้นทางเก่าที่ถูกตัด

## 3. หลักฐานและข้อมูลที่เตรียม

`PlanRevision` แยกจาก draft เก็บ revision, plan copy, savedAt และ context{remaining,floorMaterial,layout,helpUsed} เหตุการณ์ช่วยเป็นบทฝึกที่เปิดจริง ไม่ใช่ mastery หรือ assessment help log ที่ครบตามแบบอนาคต `revisionDiff` เทียบค่าทุกช่องของแผน; เงิน/ของเป็นบริบทของฉบับ แก้ข้อความใหม่ไม่เขียนทับฉบับเก่า

ยังไม่มี IndexedDB/export/import/การกู้คืน อย่าใช้คำว่าเซฟสำเร็จถาวร ป้ายบนเกมยังแจ้งข้อมูลหายเมื่อรีเฟรช

## 5. การตรวจที่ทำจริง

- `npm test`: 19 กรณีผ่าน รวมเงิน/วัสดุ/คืนเดิม, มุมกล้อง/เส้นทาง, tutorial, footprint/front, วางทับ/entry/ขอบ/ตัวละคร, ย้ายไม่ผ่าน atomic, store/undo/redo, dynamic blockers, A/Bจากค่าผู้เล่น และ snapshotฉบับแผนไม่ถูกเขียนทับ
- `npm run build`: typecheck + production build ผ่าน; มีคำเตือนขนาด bundle ของ Phaser เป็นข้อจำกัดเดิม ไม่ใช่ build ล้มเหลว
- Chromium headless ผ่าน Playwright: สอนเดินถึงโต๊ะ, กล้องหมุนซ้าย/ขวา, ตั้งค่า, เข้าออก fullscreen, วางของ/ปฏิเสธทับ/เก็บ/undo/redo, ค้นคืนวัสดุและกลับผลค้น, เปิดบทตรงช่องและกลับโฟกัส, A/Bcomparison, แผนสองฉบับ, ซื้อA/ปู/คืน/รื้อ/ปูซ้ำ, reset, ซื้อB/ปู, Escape, ข้อความ150%, ความกว้าง720px; ไม่พบ pageerror ในกรณีเหล่านี้
- ดูภาพหน้าจอโลกและสมุดข้อความ150% แล้ว ข้อความยาวเลื่อนภายในสมุด ภาพทดสอบเป็นข้อมูลสังเคราะห์ ไม่ใช่ผลเล่นจริงของผู้เรียน

ยังไม่มีผลตรวจบนเครื่อง Windows ของผู้ใช้ ครู/ผู้เรียนจริง ภาพจริงครบ4มุม โหลดเซฟ หรือพิสูจน์ประสิทธิผลการเรียน
