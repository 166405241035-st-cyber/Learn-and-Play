# กติกากิจกรรมต้นแบบ — ออกแบบพื้นที่ของฉัน
ฉบับ 0.4 — 9 ตุลาคม 2026 (Asia/Bangkok)
สถานะ: ฐานออกแบบที่ผู้ใช้ยอมรับ ยังไม่มีระบบเกม เกณฑ์ประเมินเชิงตัวเลขยังรอตรวจและทดลอง
อ่านร่วมกับ [ระบบความยาก](DIFFICULTY.md) และ [เอกสารส่งต่องาน](../PROJECT_HANDOFF.md)

## 1. เป้าหมายและเงื่อนไข
เลือกพื้นที่อ่านหนังสือ ร้านเล็ก หรือพื้นที่พักผ่อน ตั้งชื่อและจัดแบบเอง เป้าหมายเปลี่ยนรูปแบบ/เหตุผล แต่ใช้โจทย์วัสดุเดียวกันในต้นแบบ
- พื้นที่จริง 4×6 เมตร = 24 ตร.ม.; งบเฉพาะโครงการ 4,000 เหรียญ
- ส่วนเผื่อ 10% ของพื้นที่จริง = 2.4 ตร.ม.; ต้องเตรียม 26.4 ตร.ม.
- ซื้อเป็นกล่องเต็ม ใช้วัสดุชนิดเดียวต่อการทดลองรุ่นแรก
- A: 1.5 ตร.ม./กล่อง ราคา 180 → 18 กล่อง 3,240 เหรียญ ปริมาณ 27 ตร.ม.
- B: 2 ตร.ม./กล่อง ราคา 250 → 14 กล่อง 3,500 เหรียญ ปริมาณ 28 ตร.ม.
ทั้งสองแผนเป็นไปได้ ห้ามสรุปว่าแผนราคาถูกที่สุดถูกเพียงแผนเดียว ห้ามสมมติคุณภาพวัสดุที่ไม่ได้ให้ข้อมูล
ส่วนเผื่อเป็นเงื่อนไขกิจกรรม ไม่ใช่มาตรฐานงานก่อสร้างทุกประเภท

## 2. อิสระ
เลือกเป้าหมาย วัสดุ ตำแหน่งของ เวลาเรียน คำใบ้ การพัก/แก้งาน และผลงานนำเสนอได้
ห้องมีขนาดคงที่ในงานฐาน การเปลี่ยนขนาด/ผสมวัสดุเป็นกิจกรรมหรือฉบับต่อยอด
ของตกแต่งเริ่มต้นใช้ฟรี ไม่รวมต้นทุนเฟอร์นิเจอร์เข้าปัญหาวัสดุโดยเงียบ ๆ

## 3. งบ
งบแยกจากเงินทั่วไป เปิดทดลองได้รับ 4,000 ซื้อเฉพาะโครงการ คืนเข้ากองเดิม ไม่ซื้อเกินยอด ไม่มีหนี้
แสดงงบเริ่มต้น ค่าใช้จ่ายสุทธิ และยอดคงเหลือ
เงินเหลือเป็นผลวางแผน ไม่เปลี่ยนเป็นเงินทั่วไปในต้นแบบ ไม่ใช้ยืนยันความรู้
รีเซ็ตไม่โอนเงิน/ของออกไปที่อื่นและไม่เพิ่มรางวัลซ้ำ

## 4. วัสดุและการอนุรักษ์ปริมาณ
แยก: พื้นที่จริง; ส่วนเผื่อ; ปริมาณต้องเตรียม; ปริมาณซื้อ; กล่องยังไม่เปิด; วัสดุเปิดแล้วที่ยังไม่ใช้; ปูอยู่
ยังไม่จำลองการตัด/เสียหายจริง ส่วนเผื่อเป็นสำรอง
ปริมาณซื้อสุทธิ = ปริมาณในกล่องยังไม่เปิด + วัสดุเปิดแล้วที่ยังไม่ใช้ + ปูอยู่
วัสดุเหลือ = ปริมาณในกล่องยังไม่เปิด + วัสดุเปิดแล้วที่ยังไม่ใช้
เมื่อปูครบ: A เหลือ 3; B เหลือ 4 ตร.ม. ทั้งคู่ ≥ 2.4
ห้องยัง 24 ตร.ม. ไม่ใช่ 26.4 ตร.ม.

## 5. ซื้อ เปิด คืน ถอน
- ก่อนยืนยันไม่หักงบ; แสดงสินค้า จำนวน ราคา ยอดรวมก่อนซื้อ
- จำนวนเป็นเต็มบวก ตรวจเงินก่อนทำธุรกรรม ซื้อไม่พอได้ในช่วงฝึกพร้อมทางแก้
- เปิดกล่องเท่าที่จำเป็นเมื่อยืนยันปู แจ้งจำนวนล่วงหน้า
- คืนได้เฉพาะกล่องยังไม่เปิด เต็มราคาซื้อที่บันทึกกับล็อต ไม่ใช่ราคาปัจจุบัน
- คืนจำนวนเกินกล่องที่มีไม่ได้ กล่องเปิดแล้วคืนร้านไม่ได้
- ปูใช้วัสดุเปิดแล้ว ถอนคืนวัสดุเข้าคลังเต็มในโหมดทดลอง ไม่เปลี่ยนกลับเป็นกล่องปิด
- กติกาถอนคืนเต็มเพื่อทดลอง เป็นความต่างจากงานจริงที่ต้องอธิบาย
- สำรองนับทั้งกล่องปิดและวัสดุเปิดที่เหลือ ห้ามรวมสองครั้ง
- เปลี่ยนชนิดโดยถอนพื้นเดิมก่อน วัสดุเก่าอาจยังค้างในคลัง แต่ใช้ชนิดใหม่ทั้งพื้น และสำรองของชนิดที่ปูเท่านั้นยืนยันเงื่อนไข
- ราคาล็อต/ปริมาณ/เงินเปลี่ยนพร้อมกันเป็นธุรกรรมเดียว ไม่แก้แบบบางส่วนค้าง

## 6. ฟื้นตัวและทำใหม่
ก่อนซื้อแก้แผนอิสระ หลังซื้อคืนกล่องปิดได้ หลังปูถอน/ซื้อเพิ่มได้
หากงบไม่พอแก้: เสนอเริ่มทดลองใหม่ ไม่ต้องฟาร์มเงินหรือเสียสิทธิ์เรียน
เริ่มใหม่สร้างรหัสการทดลองใหม่พร้อมทรัพยากรใหม่ในโครงการเดิม เก็บสรุป/ภาพ/หลักฐานเดิม
สิ่งที่ลงพอร์ตแล้วเป็นภาพรวมฉบับเดิม แก้ผลงานภายหลังสร้างฉบับใหม่
ย้อนการวางไม่ย้อนธุรกรรมซื้อโดยอัตโนมัติ การแก้จำนวนวัสดุที่เกี่ยวข้องต้องรักษาปริมาณเสมอ
ก่อนรีเซ็ตบอกข้อมูลที่จะเปลี่ยนและให้ผู้เล่นยืนยัน

## 7. จัดพื้นที่
เลือก/วาง/ย้าย/หมุน/เก็บ/ย้อนกลับ/ทำซ้ำ/แปลน/ตาราง/ถ่ายภาพ
วางในขอบเขต ไม่ชนฐานที่ห้ามซ้อน ไม่ปิดทางเข้าและจุดจำเป็น แสดงเหตุผลวางไม่ได้
มุมบนและหน่วยจริงใช้วัด มุมเฉียงใช้ดูผลงาน ความสวยไม่เป็นคะแนนคณิตศาสตร์

## 8. สำเร็จโครงการในโลก
ตรวจครบ: ปู 24; ซื้อสุทธิชนิดที่ปู ≥26.4; สำรองชนิดเดียวกัน ≥2.4; ค่าใช้จ่ายสุทธิทุกวัสดุ ≤4,000; ทางใช้งานถึงได้; บันทึกภาพและสรุปทางเลือก
คืนกล่องหลังจบแล้วสำรองต่ำกว่าเกณฑ์: ฉบับปัจจุบันกลับเป็นต้องปรับ ภาพ/ผลประเมินประวัติไม่ถูกลบ
ความสำเร็จในโลกแยกจากความรู้ ผลงานสำเร็จได้ก่อนประเมินครบ

## 9. สอน
ต้องหาอะไร/ทำไม → ข้อมูล/หน่วย/สมมติ → หลักการ → คำนวณ/ตรวจ → ตีความ/ตัดสินใจ
ฝึกให้คำถามเจาะข้อผิด เช่น ใช้บวกหาพื้นที่, คิดเผื่อจากราคา, ปัดลง, หน่วยกล่องผิด
อย่าตัดสินวัสดุแพงกว่าว่าผิดเมื่อเงื่อนไขและเหตุผลผ่าน
บันทึกคำใบ้ตามระดับ: ชวนคิด หลักการ ตั้งคำนวณ วิธีเต็ม

## 10. ประเมิน
ฝึก / ทำเอง / จับเวลา เป็นโหมดต่างหาก จับเวลาเฉพาะท้าทายหรือสอบ
เกณฑ์: เข้าใจข้อมูล; เลือกหลักการ; คำนวณและตรวจ; ตัดสินใจ
เกณฑ์คะแนน/จำนวนหลักฐานต้องตรวจครูและทดลอง ไม่ตั้งคะแนนผ่านเพื่อเปิดระบบโดยไม่มีฐาน
งานเปลี่ยนข้อมูล: 3×5, เผื่อ10%, งบ2,100; C 1.2/กล่อง140 →14กล่อง1,960; D1.5/กล่อง180 →11กล่อง1,980
นี่วัดการใช้กับข้อมูลใหม่ ยังต้องมีบริบทใหม่เพื่อยืนยันการถ่ายโอน
ขอช่วยระหว่างประเมินแจ้งและบันทึกเป็นหลักฐานมีความช่วยเหลือ ทำต่อได้ ประเมินใหม่ใช้ฉบับใหม่
เหตุผลที่ตรวจไม่ได้เป็นรอตรวจ ไม่อ้างว่าทำเองครบและไม่ให้สิทธิ์ที่ต้องพึ่งผลนั้น
ใช้ [ระบบความยาก](DIFFICULTY.md) กำหนดเงื่อนไขเพิ่ม

## 11. รางวัล
โครงการสำเร็จ: พอร์ต/ป้าย/ตกแต่ง
ทักษะยืนยันตามเกณฑ์: โครงการเปลี่ยนขนาด/งบ
บริบทใหม่: โครงการเชื่อมหลายทักษะ
เส้นทางสอบ: งานพิเศษระยะต่อยอด
สิทธิ์มีรหัส ได้ครั้งเดียวตามผู้เล่น/เงื่อนไข ไม่ให้ซ้ำเมื่อโหลดหรือรีเซ็ต
รางวัลที่ได้จากหลักฐานประวัติไม่หายเมื่อย้ายของ แต่ผลปัจจุบันกับหลักฐานเก่าต้องแสดงแยกกัน

## 12. พอร์ต
ผู้เล่นแก้ชื่อ ภาพปก เป้าหมาย เหตุผล สิ่งที่แก้และสะท้อนคิด
ระบบเก็บขนาด เงื่อนไข วัสดุ งบ แผน ผลงาน สำรอง หลักฐาน ช่วยเหลือ ผล/รอตรวจ วันที่ ฉบับกิจกรรม และรายละเอียดความยาก
เก็บแผนแรก แผนใช้จริง และฉบับสำคัญ ไม่จำเป็นต้องแสดงทุกคลิก
แก้ข้อความไม่เปลี่ยนผลประเมิน ห้ามแสดงเชี่ยวชาญเมื่อหลักฐานไม่พอ

## 13. เซฟ
บันทึกโครงการ/ทดลอง แผน ล็อตซื้อคืน วัสดุ พื้นที่ บท/คำใบ้ งานประเมิน ผล พอร์ต รางวัล ตั้งค่า และฉบับ
IndexedDB + ส่งออก/นำเข้า ไม่ล็อกอินต้นแบบ
ตรวจไฟล์/ฉบับและสำรองก่อนนำเข้า จำกัดขนาดภาพและออกแบบกู้คืน
เงิน/วัสดุ/ธุรกรรม/สิทธิ์ต้องสอดคล้อง โหลดไม่สร้างผลซ้ำ ข้อมูลจริงของผู้เล่นไม่ใส่ GitHub

## 14. สถานะและเหตุการณ์สำหรับขั้นข้อมูล
Project: draft → active → ready_to_summarize → portfolio_stored; paused เก็บสถานะก่อนพักเพื่อกลับถูกจุด
สถานะประเมินแยก: draft/submitted/partially_pending/reviewed; ระดับการช่วยเก็บแยกสถานะ
เหตุการณ์: start_attempt, save_plan, buy, return_sealed, open_boxes, place_floor, remove_floor, edit_layout, submit_assessment, review_result, grant_unlock, store_portfolio, reset_attempt
แต่ละเหตุการณ์มีรหัสป้องกันทำซ้ำ เป้าหมาย/ทดลอง ฉบับ เวลาที่เกิด และข้อมูลผล ห้ามนำเหตุการณ์ย้อนหลังไปรับเงินซ้ำ

## 15. ตรวจรับต้นแบบ
- ปริมาณวัสดุสมดุลก่อน/หลังซื้อ คืน เปิด ปู ถอนและโหลด
- งบไม่ติดลบหรือเพิ่มจากคืนเกินจำนวน
- ทั้ง A/B ผ่านงานได้
- เปลี่ยนวัสดุไม่ใช้สำรองชนิดเก่ามายืนยันชนิดใหม่
- งานฝึก/ช่วย/ทำเอง/รอตรวจแสดงต่างกัน
- เริ่มใหม่ไม่ลบหลักฐานเดิมหรือรับรางวัลซ้ำ
- พอร์ตมีเงื่อนไขหลักฐานและแผนฉบับที่ตรงงาน
- เข้าถึงเรียนได้แม้ยังไม่ผ่าน
- งานขั้นสูงไม่อ้างว่าใช้ได้แล้วก่อนเขียนตัวตรวจและเนื้อหา
