# Learn-and-Play — แบบออกแบบต้นแบบครบวงจร
ฉบับ 0.6 — 9 ตุลาคม 2026 (Asia/Bangkok)
สถานะ: เอกสารออกแบบเพื่อพัฒนาต่อ ยังไม่มีเกมที่รันได้

## 1. ขอบเขตและสถานะ
เอกสารนี้รวมระบบให้เชื่อมกัน ไม่แทนกติกาทรัพยากรใน [PROTOTYPE_RULES](PROTOTYPE_RULES.md) หรือสามแกนใน [DIFFICULTY](DIFFICULTY.md) หากรายละเอียดใหม่ขัดกันให้แก้เอกสารและบันทึกเหตุผลก่อนเขียนโค้ด

| สถานะ | รายการ |
| --- | --- |
| เป้าหมายตกลงแล้ว | Sandbox คณิตศาสตร์มัธยม สอนตรง ๆ ประเมินจากหลักฐาน พอร์ต และรองรับวิชาอื่นในอนาคต |
| กติกายอมรับแล้ว | พื้นที่4×6 งบ4000 เผื่อ10% ซื้อกล่องเต็ม คืนเฉพาะกล่องปิด ทดลองใหม่ได้ ความยากสามแกน |
| แนวทางเทคนิค | Desktop browser, TypeScript/Phaser, HTML/CSS panels; Vite/npm และ IndexedDB เป็นแนวทางที่ยังไม่ได้ลงระบบ |
| รายละเอียดเสนอในฉบับนี้ | พฤติกรรมหน้าจอ อุปกรณ์จัดพื้นที่ การวางตัวละคร ขั้นบทเรียน โครงสร้างการตรวจ และระยะพัฒนา |
| มีจริงใน repository | เอกสารออกแบบ/ข้อกำหนด/พร็อมป์และข้อมูลสังเคราะห์ |
| ยังไม่มี | โค้ดเกม ตัวตรวจ เซฟ พอร์ตที่ใช้งาน ภาพ/เสียงจริง โฮสต์ และหลักสูตรที่ตรวจครบ |

ไม่สร้างภาพในงานนี้ ผู้ใช้สร้างภายนอกตามพร็อมป์ ไม่เปิดบัญชี/บริการเสียเงินหรือ deploy ระหว่างออกแบบ

## 2. สิ่งที่ต้นแบบต้องพิสูจน์
ผู้เล่นเลือกเป้าหมายเอง เข้าใจปัญหา เลือกข้อมูลและวิธี แก้แผนได้ เห็นผลโลก ทำงานประเมินอีกชุด และเก็บผลงานที่บอกเงื่อนไขจริงได้ ต้องแสดงความสำเร็จในโลก ผลตรวจความรู้ และรายการพอร์ตแยกกัน
ต้นแบบไม่ต้องพิสูจน์ครอบคลุมคณิตศาสตร์ทุกบท ไม่อ้างว่าเพิ่มผลสอบหรือประสิทธิผลการเรียนรู้จากคะแนนก่อน/หลังอย่างเดียว

## 3. เส้นทางเล่นครบวงจร
ลำดับต่อไปเป็นเส้นทางตัวอย่าง ไม่ใช่การบังคับเล่นเรียงทุกครั้ง ผู้เล่นกลับไปเรียน/ร้าน/จัดพื้นที่ได้หลังการเริ่มต้น

| ช่วง | สิ่งที่ผู้เล่นเห็นและทำ | สิ่งที่เรียน/หลักฐาน | ระบบ/ทางกู้คืน |
| --- | --- | --- | --- |
| เข้าโลก | คำแนะนำคลิกเดิน เปิดแปลน ปรับตัวหนังสือ/เสียง/ลด motion | ไม่ประเมินจากการใช้เมาส์ | เริ่มใหม่หรือโหลด; ไม่บังคับบัญชี |
| เลือกเป้าหมาย | ห้องอ่าน ร้านเล็ก หรือพักผ่อน พร้อมตั้งชื่อ | เหตุผลส่วนบุคคล ยังไม่เป็นคะแนน | เปลี่ยนเป้าหมายได้; มิติพื้นที่เท่ากันในงานฐาน |
| สำรวจเงื่อนไข | ป้าย4×6เมตร งบ4000 เผื่อ10% ร้านA/B | แยกหน่วยและสิ่งที่ต้องหา | ข้อมูลสำคัญเปิดอ่านซ้ำได้ไม่พึ่งจำบทสนทนา |
| เลือกวิธีเริ่ม | เรียนก่อน หรือเริ่มร่างแผน | ผู้รู้แล้วไม่ต้องฝึกซ้ำ | ความช่วยเข้าถึงตลอด |
| เรียนและร่างแผน | อ่าน/ลองทีละขั้น กรอกข้อมูลและเหตุผล | แผนแรก คำใบ้ เครื่องมือ | บันทึกร่างเมื่อเปลี่ยนหน้า |
| เปรียบเทียบ | ปริมาณ กล่อง ค่าใช้จ่าย สำรอง งบเหลือ | เห็นว่าหลายทางเลือกผ่านได้ | ไม่ตีBผิดเพียงแพงกว่า |
| ซื้อ | ตะกร้าและยอดก่อน/หลัง | การใช้แผนกับข้อจำกัด | ซื้อไม่พอในฝึกได้ ซื้อเกินงบไม่ได้ คืนกล่องปิดได้ |
| จัดพื้นที่ | ปู ย้าย หมุน เก็บ และมุมแปลน | เห็นพื้นที่จริง24ไม่ใช่26.4 | ถอนคืนวัสดุในโหมดทดลอง แก้ทางเดินได้ |
| ตรวจโครงการ | รายการพื้นที่/สำรอง/งบ/ทางเข้า | อธิบายผลจากแผน | ข้อไม่ผ่านบอกจำนวน/เหตุผลและทางแก้ |
| สรุปผลงาน | ภาพ เป้าหมาย แผนใช้จริง เหตุผลและสิ่งที่แก้ | หลักฐานการประยุกต์ในโครงการ | บันทึกพอร์ตได้ก่อนประเมินครบ |
| ประเมินข้อมูลใหม่ | งาน3×5 C/D ไม่จับเวลา | คำตอบ เหตุผล การตรวจและช่วยที่ใช้ | ถามช่วยได้; ไม่แก้งานเดิมเป็นทำเอง |
| ดูผล | ตัวเลขที่ตรวจได้/ด้านรอตรวจ/ข้อแนะนำ | ไม่รวม pending เป็นผ่าน | เลือกฝึกหรือทำงานใหม่ |
| กลับมาเล่น | เปิดพอร์ต แก้โครงการ หรือเริ่มเป้าหมายใหม่ | เห็นพัฒนาการพร้อมเงื่อนไข | โหลดไม่ซื้อ/ให้รางวัลซ้ำ |

## 4. โลก Sandbox และการควบคุม
ใช้แผนที่32×24และโซนจาก handoff เป็นแบบทดลอง จัดให้พื้นที่ส่วนตัว ร้าน ศูนย์เรียน บอร์ดพอร์ตเชื่อมด้วยเส้นทางที่เดินถึงได้ก่อนเพิ่มของตกแต่ง

| การกระทำ | พฤติกรรมเสนอ |
| --- | --- |
| คลิกพื้น | เดินต่อเนื่องตามเส้นทางไปเซลล์ที่ไปถึงได้; เป้าหมายไม่ได้ให้แจ้ง ไม่ teleport |
| คลิกวัตถุ/NPC | เดินไปจุด interaction ที่ว่าง แล้วเปิดเมนู; ยกเลิกได้เมื่อคลิกเป้าหมายใหม่ |
| เลื่อนกล้อง/ซูม | ปุ่มและเมาส์ มีขอบเขต ไม่ทำให้หลงออกจากแผนที่; ปุ่มกลับตัวละคร |
| ลากของ | preview footprint และข้อความวางได้/ไม่ได้; ปล่อยนอกแผนยกเลิก |
| หมุนของ | footprint เปลี่ยนตามทิศ; artwork ต้องรองรับ ห้ามหมุนภาพมุมเฉียงผิดเอง |
| Escape | ปิด overlay หรือยกเลิกวาง; ไม่ทิ้งร่างโดยไม่แจ้ง |
| คีย์บอร์ด | Tab/Enter ใช้ panel; ปุ่มเลือกเซลล์/วางแบบไม่ลากเป็นทางเลือกที่ต้องพัฒนา |

โหมดสำรวจ/จัดพื้นที่/แปลนใช้ข้อมูล logical grid เดียวกัน ห้ามวัดจากพิกเซลมุมเฉียง เวลาโลก/resource pause เมื่ออ่านแผน บทเรียน และประเมินทั่วไป เสียง/animation ambient ไม่จำเป็นต้องหยุด แต่ลดสิ่งรบกวน
NPC3บทบาท: ผู้ขายอธิบายสินค้า ผู้ช่วยเรียนชวนคิด สมาชิกชุมชนสะท้อนการใช้พื้นที่ ไม่มี NPC ให้คำตอบเต็มโดยไม่บันทึกช่วยระหว่างประเมิน
รุ่นแรกไม่มี hunger/เสียค่าเช่า/วัสดุเสียหายสุ่ม/ตลาดผันผวน จนกว่าจะออกแบบผลต่อการเรียนและการกู้คืน

## 5. การก่อสร้างและทรัพยากร
พื้นที่จริง4×6เซลล์ เซลล์ละ1m² ปูด้วยวัสดุชนิดเดียว ของตกแต่งเริ่มต้นฟรีและไม่เพิ่มโจทย์ราคาโดยเงียบ ๆ
ชุดทดลองเสนอ: โต๊ะ2×1 เก้าอี้1×1 ชั้นหนังสือ1×1 ม้านั่ง2×1 กระถาง1×1 ให้จำนวนจำกัดเพื่อลดรกแต่ไม่มีค่าใช้จ่ายคณิตศาสตร์เพิ่มเติม
ต้องกำหนดจุดทางเข้ากับจุดใช้งานเฟอร์นิเจอร์เป็นข้อมูล ไม่ตัดสินจากภาพสวย ทางเดินเสนอใช้ flood-fill เซลล์ที่เดินได้จากประตูไป interaction points สำคัญ; รายการจุดสำคัญต้องให้ผู้เล่นเห็น
ของพื้น/ของบนพื้นมี collision ต่างกัน; ปูพื้นไม่ปิดทางเดิน วัตถุที่ห้ามซ้อนชนกันไม่ได้ เก็บของไม่ขาย/คืนเงิน
undo/redo เฉพาะจัดพื้นที่; การปู/ถอนต้องย้ายวัสดุจริงอย่างสมดุล ไม่ย้อนซื้อโดยอัตโนมัติ

### ตัวอย่างวงจรวัสดุ A
ซื้อ18กล่อง=27m² ค่า3240; เปิด16กล่อง=24m² ปูครบ; กล่องปิด2=3m² งบเหลือ760
ถ้าคืนกล่องปิด1ได้180 งบเหลือ940แต่สำรองเหลือ1.5<2.4 โครงการปัจจุบันต้องปรับ แม้พอร์ตฉบับก่อนยังเก็บผลตอนสำเร็จ
ถ้าถอนพื้นที่24จะได้วัสดุเปิด24 กล่องปิดยัง1 ไม่กลายเป็นกล่องปิด17 ถ้าเปลี่ยนB สำรองAไม่ใช้ยืนยันพื้นB
reset สร้างการทดลองใหม่งบ4000และเก็บงานเก่า ไม่มีการโอนของหรือเปลี่ยนเงินเหลือเป็นเงินทั่วไป

## 6. บทเรียนและการฝึก
ทุกบทมี purpose/data/principle/calculation-check/decision สั้นพออ่านระหว่างเล่น มีตัวอย่างเต็มแยกจากช่องทำเองและย้อนดูได้

| ทักษะต้นแบบ | คำถาม/หลักการที่สอน | ข้อผิดที่ให้ feedback |
| --- | --- | --- |
| หน่วยและข้อมูล | เมตรวัดด้าน ตารางเมตรวัดพื้นที่ กล่องคือหน่วยซื้อ | ใช้เมตรกับพื้นที่; เอาราคาเป็นฐานเผื่อ |
| พื้นที่สี่เหลี่ยม | 4แถว/6หน่วยตามแปลน; กว้าง×ยาว=24m² | 4+6คือรวมความยาวบางด้าน ไม่ได้พื้นที่ |
| ร้อยละเผื่อ | 10%ของ24=2.4; เตรียม26.4 ไม่เปลี่ยนห้อง | ใช้24+10; เพิ่มพื้นที่จริงเป็น26.4 |
| กล่องเต็ม | 26.4÷1.5=17.6 ต้อง18เพื่อให้พอ | ปัดลง17ได้25.5ไม่ถึง26.4 |
| งบและทางเลือก | ราคา×กล่อง; งบ−ค่าใช้จ่าย; ตรวจสำรอง | ถูกที่สุดเป็นคำตอบเดียว; สมมติคุณภาพที่ไม่ได้ให้ |
| ตรวจและตีความ | ซื้อ27 ปู24 เหลือ3≥2.4; อธิบายเหตุผล | นับสำรองซ้ำ; ดูแต่คำตอบท้าย |

ฝึกเสนอ mini-task ทีละทักษะแล้วกลับโครงการ ไม่ให้เรียนทุกบทเป็นประตูบังคับ คำตอบผิดบอกขั้นที่ติดและคำถามช่วย ไม่ใช้เสียงลงโทษหรือเสียเงินเพื่อบังคับเรียน
ถ้าใช้ตัวอย่างเต็ม ผลช่วงนั้นเป็น assisted practice ข้อสอบ/งานใหม่ต้องบันทึกเงื่อนไขใหม่โดยไม่ลบประวัติ

## 7. ความยากและกิจกรรมต่อยอด
สามแกนแยก: ความช่วย ความซับซ้อน และความเปิดกว้าง จับเวลาเป็นเงื่อนไขเสริม ไม่ใช่ระดับทั่วไป

| ระยะ | เส้นทาง | เงื่อนไขก่อนเปิด |
| --- | --- | --- |
| ต้นแบบ | GUIDED4×6 + INDEPENDENT3×5 | บทสอนฐาน ตรวจตัวเลข บันทึกช่วยและรอตรวจ |
| เพิ่มหลายขั้น | COMPAREค่าส่ง/ส่วนลด | สอนฐานส่วนลด กฎปัดราคาและตัวตรวจครบ |
| เพิ่มรูปทรง | SHAPEพื้นที่เว้า | แปลนส่วนที่ตัดแน่นอน บทพื้นที่ประกอบ และเส้นทางเดินตรวจได้ |
| โครงการกำหนดเอง | OPENขนาด3–5×4–6 | กำหนดงบ/ชุดวัสดุที่มีทางออกทุกชุด ตัวตรวจและ rubric โครงการเปิด |
| ท้าทายสอบ | จับเวลาตามเป้าหมาย | เนื้อหา/เวลาผ่านการตรวจและทางเลือกเล่นทั่วไปยังอยู่ |

ไม่เปลี่ยนโจทย์กลางงานโดยเงียบ ๆ เปลี่ยนข้อมูลสร้างงานใหม่เก็บร่างเดิม เปลี่ยนช่วยในงานเดิมได้พร้อมบันทึก แนะนำรายทักษะจากหลักฐาน ไม่จัดผู้เล่นเป็นเก่ง/อ่อนจากเวลาเล่น เงิน หรือความสวย

## 8. การประเมินและการตรวจเหตุผล
สี่ด้าน:เข้าใจข้อมูล เลือกหลักการ คำนวณ/ตรวจ ตีความ/ตัดสินใจ อ่าน [ตัวอย่าง rubric](../assessment/RUBRIC_EXAMPLES.md)
ข้อเสนอ runtime แรก: เก็บตัวเลขและเหตุผลเป็นช่องแยก ตรวจตัวเลข/หน่วย/เงื่อนไขที่นิยามแน่นอนได้ เหตุผลอิสระส่ง pending ถ้ายังไม่มีผู้ตรวจ การดูตัวอย่างเฉลยหลังส่งเป็น feedback ไม่ใช่ self-certification
ไม่มี AI grader บังคับ ไม่มีการอ้างว่าผู้ตรวจออนไลน์พร้อมแล้ว ไม่ให้ mastery/unlock ที่ต้องอาศัยเหตุผลเมื่อไม่มีผลยืนยัน วิธีครูตรวจเป็นงานต่อยอดที่ต้องกำหนดผู้มีสิทธิ์/ประวัติการแก้ก่อนใช้งาน

| ประเภทหลักฐาน | ข้อสรุปที่อนุญาต |
| --- | --- |
| ทำตามวิธีเต็ม | สำเร็จพร้อมความช่วยเหลือ |
| ตัวเลขถูกแต่เหตุผล pending | ตัวเลขผ่านการตรวจตามเงื่อนไข; ด้านอื่นยังรอตรวจ |
| งานข้อมูลใหม่บริบทเดิม | ใช้ความรู้กับข้อมูลใหม่ ไม่ใช่ broad transfer |
| งานบริบทใหม่ที่ตรวจแล้ว | ประยุกต์ในบริบทที่ระบุ ไม่เหมารู้ทุกบท |
| รอบหลังเว้นระยะ | หลักฐาน retention ตามช่วง/การทบทวนจริง ไม่รับรองถาวร |

pre/post ให้ชุดเทียบเคียง ไม่ใช้ชุดเดิมที่จำเฉลยเพียงชุดเดียว ระยะติดตาม จำนวนงาน เกณฑ์ยืนยันและความสอดคล้องผู้ตรวจต้องทดลอง/ทบทวนครู ไม่มี80%มาตรฐานร่วมทุกเรื่อง

## 9. ความก้าวหน้าและรางวัล
โลก:โครงการ/สิ่งปลูกสร้าง/ของตกแต่ง ความรู้:ผลรายทักษะและเงื่อนไข พอร์ต:ผลงานที่ผู้เล่นเลือก ทั้งสามข้อมูลแยกกัน
รางวัลต้นแบบเสนอป้ายและแบบตกแต่งเมื่อสรุปโครงการสำเร็จ ไม่แปลงงบเหลือเป็นเงินจริง ไม่ให้ mastery จากรางวัล
รางวัลความรู้ยังปิดจนเกณฑ์ยืนยันพร้อม แต่ห้ามปิดบทเรียน/คำใบ้/การประเมินความรู้เดิม งานยากต้องเข้าถึงความช่วยและมีวิธีเลือกเริ่มอย่างเหมาะสม
ให้สิทธิ์ด้วย rule/version/scope idempotency key โหลดหรือresetไม่เพิ่มสิทธิ์ซ้ำ งานโลกเปลี่ยนไม่ลบผลประเมินประวัติ

## 10. พอร์ต
หน้าแรก:ผลงานเด่น ทักษะพร้อมเงื่อนไข พัฒนาการ และฝึกต่อ กรองโครงการ/ทักษะ/วันที่/วิชา
หน้าผลงาน:เป้าหมาย ภาพ เงื่อนไข แผนแรก/แผนใช้จริง ตัวเลขสำคัญ เหตุผล สิ่งที่แก้ สรุปโลก ผลประเมิน/ช่วย/รอตรวจ และสะท้อนคิด
ข้อความเสนอ:“โครงการสำเร็จ | ผลคำนวณตรวจแล้ว | เหตุผลรอตรวจ” ไม่แสดง badgeเชี่ยวชาญแทนpending
แก้ชื่อ/ปก/สะท้อนคิดได้ แต่ไม่แก้ผลตรวจ แก้โครงการจริงสร้างเวอร์ชันใหม่และเชื่อมเวอร์ชันก่อน ไม่เขียนทับ snapshot
การจัดอันดับ แชร์สาธารณะ PDFพอร์ต และ teacher dashboard เป็นระยะหลัง ไม่มีเผยแพร่คำตอบ/ข้อมูลผู้เล่นอัตโนมัติ

## 11. หน้าจอและการเข้าถึง
