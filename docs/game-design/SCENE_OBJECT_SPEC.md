> Camera revision: physical grid/footprints/interaction cells below remain unchanged. Rendering now supports four quarter-turn views; inverse picking, depth and contact anchor must use the current view. The baseline (x+w,y+h) anchor applies to view 0 only. See [GAME_UI_REVISION](../ui/GAME_UI_REVISION.md).


ฉบับเสนอ0.1 — 9ตุลาคม2026; บันทึกแบบที่คุยและแก้จุดพิกัด ยังไม่ทดสอบเกม/ภาพจริง

## 1. ระบบพิกัด

grid32×24; x0–31เพิ่มไปeast y0–23เพิ่มไปsouth; ช่อง1×1m ขอบเขตรวมปลาย
ฉายมุมเฉียง screenX=(x−y)×64 screenY=(x+y)×32 บวกorigin; logical eastเป็นด้านขวาล่าง/SEของจอ logical southเป็นด้านซ้ายล่าง/SWของจอ หน่วยmeasureใช้แปลนมุมบนไม่ใช้pixelภาพ
ฐานวัตถุเป็นเซลล์ชน ภาพยื่น/สูงได้ จุดanchorworldเป็นจุดฉายของมุมฐานที่อยู่ล่างสุด (x+width,y+height); pixelanchorของภาพต้องตรงจุดนี้ artไม่เปลี่ยนlogic footprint
ใช้4-neighbourเดินไม่มีdiagonalตัดมุม; ไม่ใช้diagonalระยะ√2สำหรับข้อวัดในชุดนี้ Playerเริ่ม(15,14) จุดเริ่มไม่มีcollision

## 5. พื้นและundo

ข้อเสนอscopeต้นแบบปู/ถอนทั้ง24m²ในคำสั่งเดียว อ่านวัสดุเปิดเหลือก่อนแล้วเปิดsealedขั้นต่ำที่ขาด แสดงจำนวนก่อนยืนยัน open+placeอยู่transactionเดียว; ยอดrequired26.4ใช้เงื่อนไขซื้อ/สำรองไม่ใช่ปริมาณปู
undoเฟอร์นิเจอร์เปลี่ยนlayoutเท่านั้น undoพื้นต้องโยกmaterialตามจริง ถ้าstateเปลี่ยนจนredoไม่ได้บอกเหตุผลและไม่สร้างวัสดุ undoไม่ย้อนซื้อ/คืนหรือgrant/reset
เปลี่ยนชนิดให้ถอนทั้งหมดก่อน ไม่ปูผสมในattemptนี้; สำรองวัสดุเก่าไม่ยืนยันชนิดใหม่
