# Windows — สถานะหลังล้างต้นแบบ

9 ตุลาคม 2026

ตอนนี้โครงการอยู่ขั้นออกแบบใหม่ ไม่มี package.json, src หรือเกมให้รัน `npm.cmd ci` / `npm.cmd run dev` จากคำแนะนำเดิมจึงใช้ไม่ได้กับmainปัจจุบัน ยังไม่ต้องติดตั้ง scaffold ใหม่

ผู้ใช้เคยตรวจเครื่อง: Node22.19.0, npm10.9.3 และ Git2.55.0.windows.4 เครื่องมือยังใช้ต่อสำหรับงานอนาคตได้ แต่ต้องตรวจความเข้ากันได้เมื่อเลือกdependenciesใหม่ ไม่มีเหตุผลให้เปลี่ยนNodeเพียงเพราะล้างโครงการ

เปิดTerminalในโฟลเดอร์GitของLearn-and-Play:

```powershell
git status
git pull --ff-only origin main
```

Pullเมื่อไม่มีงานค้างที่จะถูกทับ ถ้ามีการแก้ของตัวเองให้เก็บก่อน ไม่ใช้reset --hardเพื่อลบทิ้ง หลังpullให้อ่าน [GAME_CONCEPT](GAME_CONCEPT.md) เป็นหลัก ไฟล์node_modules/distที่เคยสร้างบนเครื่องเป็นผลจากต้นแบบเดิม ไม่ใช่เกมใหม่

ยังไม่มีURLเผยแพร่ บัญชีผู้เล่น backend หรือระบบเซฟใหม่ เมื่ออนุมัติให้เขียนต้นแบบใหม่แล้วจึงเพิ่มคำสั่งติดตั้ง/รันที่ตรวจจริง ไม่รันcreate-viteใส่รากโครงการก่อนคุยโครงสร้างและรักษาภาพคอมมิช
