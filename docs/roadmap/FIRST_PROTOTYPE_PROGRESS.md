ข้อมูลอยู่ในหน่วยความจำของแท็บนี้เท่านั้น ไม่มี IndexedDB/localStorage/export/import รีเฟรชแล้วหาย ข้อความ “เก็บฉบับแผน” หมายถึงในรอบเปิดหน้านี้ หน้าจอแจ้งข้อจำกัดและเตือนก่อนออกเมื่อมีงานเปลี่ยน

ผล “เงื่อนไขวัสดุครบ” ตรวจเฉพาะพื้นจริงและสำรอง ยังไม่ใช่โครงการเสร็จครบการจัดของ/ภาพ/สรุป และไม่ใช่ผลประเมินความรู้ ไม่มีรางวัลหรือปลดสิทธิ์

บทเรียนใน UI เป็นข้อความฝึกต้นแบบจากชุดแรก ไม่ใช่หลักสูตรที่ผ่านครูตรวจครบแล้ว ความช่วยในงานประเมินยังไม่ได้บันทึกเพราะยังไม่มีหน้าประเมิน

## 2. สิ่งที่ยังไม่มี

- วาง/ลาก/หมุน/เก็บเฟอร์นิเจอร์และตรวจทางเข้าด้านหน้า
- NPC เคลื่อนที่/บทสนทนา, เลื่อนกล้อง, roof occlusion, ภาพจริงและเสียง
- งานประเมิน C/D, เงื่อนไขเครื่องมือ/คำใบ้/การเคยเห็นโจทย์, ส่งคำตอบ immutable, ตัวเลขแยกเหตุผลรอตรวจ
- พอร์ต ภาพผลงาน สรุป รางวัล และสิทธิ์ความรู้
- เซฟถาวร กู้คืน ส่งออก/นำเข้า และ migration
- ตัวเลือกความยากขั้นสูง/โจทย์อื่น/หลักสูตรวิชาอื่น
- Hosting, บัญชีผู้เล่น, เซฟออนไลน์ และผลทดลองกับผู้เรียน/ครู

## 4. สิ่งที่ผู้ใช้ต้องทำตอนนี้

1. Pull บนเครื่อง Windows โดยเก็บงานที่แก้เองก่อน หาก git status มีการแก้ให้ส่งสถานะมา ไม่สั่งลบทิ้ง
2. รัน npm.cmd ci และ npm.cmd run dev จากโฟลเดอร์ที่มี package.json เปิด URL ใน Terminal
3. ลองรายการตรวจด้านล่าง แล้วบอกจุดติด/ข้อความที่ไม่เข้าใจ ภาพหน้าจอหรือข้อความ error ถ้ามี ไม่ต้องส่งข้อมูลส่วนตัว/โทเคน
4. สร้างภาพตัวอย่างภายนอก 5 ชิ้น: ผู้เล่นยืน SE, เดิน SE เฟรม 01/02, พื้นหญ้า, โต๊ะหันทิศ logical S ตาม PROTOTYPE_PRODUCTION/PROTOTYPE_PROMPTS เก็บต้นฉบับ ชื่อไฟล์และเงื่อนไขการใช้ แล้วตรวจขนาด/จุดยึดก่อนผลิตครบ
5. ให้ครูช่วยตรวจบทสอน โจทย์ C/D และตัวอย่างเกณฑ์เหตุผล บันทึกข้อแก้และวันตรวจ ไม่ใส่ป้ายอนุมัติจนมีผลตรวจจริง

ข้อ 4–5 ทำคู่ขนานได้ ต้นแบบใช้ภาพชั่วคราวต่อได้ และยังไม่ให้สิทธิ์ความรู้จากเกณฑ์ที่รอตรวจ

```powershell
git status
git pull --ff-only origin main
npm.cmd ci
npm.cmd run dev
```

หยุดด้วย Ctrl+C ตรวจเพิ่มเติมได้ด้วย npm.cmd test และ npm.cmd run build ไม่เปิด index.html ตรง ๆ ไม่มี URL เกมเผยแพร่ในรอบนี้

## 6. หลักฐานการตรวจของผู้ช่วย

- สภาพแวดล้อมผู้ช่วย Node 24.19.0 / npm 11.9.0 แยกจากเครื่องผู้ใช้ Node 22.19.0 / npm 10.9.3
- ตรวจ metadata ของ Vite 8.3.4: Node ^20.19.0 หรือ >=22.12.0; TypeScript 5.9.3: >=14.17; package engines ของโครงการเลือก Node 22.12+ หรือ 24+ เวอร์ชันตั้งต้นของผู้ใช้รองรับตามเงื่อนไข แต่ยังไม่ได้ทดสอบบน Windows ของผู้ใช้
- npm test ผ่าน 10 กรณี: A/B, A17, คืนแล้วสำรองไม่พอ, รื้อ/ปูซ้ำ, งบ/คำสั่งไม่ผ่านไม่แก้ state, replay ไม่หักซ้ำ, หลายล็อต, reset/ฉบับแผน, สำรองต่างชนิด, navigation/projection
- Chromium 153 headless: คลิกศูนย์เรียนแล้วเดินไปเปิดบท, แผน/กลับโฟกัส, ตรวจฝึก, ยืนยันตะกร้า, A ซื้อ/ปู/คืน/รื้อ/ปูซ้ำ, reset และ B, Escape, 150% และ 720px; ไม่มี pageerror และตรวจภาพแล้ว
- Build มีคำเตือน chunk ของ Phaser รวมกับแอปประมาณ 1.24 MB ก่อน gzip (~331 KB gzip) ไม่ใช่ build failure; การแยกโหลด/ประสิทธิภาพเป็นงานตรวจเพิ่มก่อนเผยแพร่ ไม่ซ่อน warning โดยเพิ่ม threshold
- นี่เป็นการตรวจต้นแบบ ไม่ใช่ผลทดลองการเรียนรู้หรือการรับรองหลักสูตร

## 7. จุดเชื่อมเพื่อทำต่อ

- `src/content/first-project.ts`: เงื่อนไข วัสดุ บทเรียน; `scene-layout.json`: ผัง runtime อ้างแหล่งออกแบบเดิม
- `src/domain/project.ts`: pure command/state ในหน่วยความจำ ไม่ผูก DOM/Phaser
- `src/domain/navigation.ts`: footprint/BFS/projection ใช้ทดสอบโดยไม่มีเกม
- `src/world/WorldScene.ts`: ฉาก/เดิน/จุดใช้งาน/ภาพชั่วคราว
- `src/main.ts`, `style.css`: หน้าฝึก/ร้าน/คลัง/ข้อความและการเข้าถึง
- `tests/*.test.mjs`: ตรวจตรรกะผ่าน TypeScript ที่ compile ไป .test-build (ignored)

เพิ่มข้อมูล/กติกาให้ใช้ version/snapshot ตาม DATA_CONTRACTS ในระยะที่เกี่ยวข้อง อย่าสมมติว่าสัญญาเซฟฉบับเต็มถูก implement แล้วจาก state ต้นแบบนี้
